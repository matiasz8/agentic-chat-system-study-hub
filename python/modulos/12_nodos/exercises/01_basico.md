# Ejercicio 01 — SimpleProcessor

Crea un nodo llamado `simple_processor` que reciba un `TypedDict` con `raw_text` y devuelva un texto normalizado.

## Requisitos
- Debe usar `TypedDict`.
- Tiene que registrar el paso ejecutado en una lista acumulable.
- Debe convertir el texto a minúsculas y remover espacios duplicados.

## Caso de prueba
Entrada: `"  INCIDENTE   crítico "`

Salida esperada: `"incidente crítico"`

Ver `../solutions/01_basico.py`.
