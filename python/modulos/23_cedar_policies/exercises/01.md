# Ejercicio 1: PolicyStore básico

## 🎯 Objetivo

Evaluar una solicitud simple `(principal, action, resource)` con reglas `permit` y `deny`.

## 📋 Descripción

Crea una clase `PolicyStore` que guarde políticas básicas y exponga un método `evaluate(principal, action, resource)`.

Tu motor debe aplicar estas reglas:

- si encuentra un `forbid`, devuelve denegado;
- si encuentra un `permit` y no hay `forbid`, devuelve permitido;
- si no encuentra ninguna regla, aplica `default deny`.

## 💡 Pistas

- Modela las políticas con `dataclass`.
- `fnmatch` puede ayudarte con comodines como `doc:*`.
- Piensa en una función auxiliar `_match(pattern, value)`.

## ✅ Criterios de Éxito

- Soporta al menos 3 políticas.
- Respeta la precedencia de denegación explícita.
- El programa imprime varias evaluaciones de ejemplo.
- Todo corre con stdlib.

## 🚀 Bonus

Agrega una explicación textual de por qué se tomó cada decisión.
