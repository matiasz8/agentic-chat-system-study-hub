# 🚀 Quick Start

Cómo empezar en 15 minutos.

---

## ✅ Requisitos Previos

- Python 3.9+
- Node.js 16+
- Git
- Editor de código (VS Code recomendado)

---

## 📦 Setup Inicial

### Paso 1: Clonar el Repositorio

```bash
git clone https://github.com/matiasz8/agentic-chat-system-study-hub.git
cd agentic-chat-system-study-hub
```

### Paso 2: Instalar Node.js (para Documentación)

```bash
npm install
```

### Paso 3: Instalar Python (para Código)

```bash
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate
pip install -r python/requirements.txt
```

---

## 🌐 Correr Documentación Localmente

```bash
npm run dev
```

Abre: **http://localhost:3000**

Verás el hub completo con sidebar, búsqueda y dark mode.

---

## 🐍 Ejecutar Primer Ejemplo Python

```bash
python python/modulos/00_vercel_intro/examples/01_basico.py
```

Deberías ver: "✅ Vercel intro ejecutado correctamente"

---

## ✅ Verificar Instalación

```bash
python python/test_setup.py
```

Si ves ✅ en todo, estás listo para empezar.

## 🐛 Solucionar Problemas

### Python: "ModuleNotFoundError: No module named 'langgraph'"
```bash
pip install --upgrade -r python/requirements.txt
```

### Node: "npm: command not found"
Instala Node.js desde https://nodejs.org/

### Nextra no arranca
```bash
rm -rf .next node_modules
npm install
npm run dev
```
