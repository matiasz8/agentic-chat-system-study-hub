# Ask Sage MVP: Q&A Agent Médico

## Descripción
Agente RAG (Retrieval-Augmented Generation) que responde preguntas sobre medicamentos y salud.

## Contenido
- Búsqueda vectorial básica
- Ranking de relevancia con TF-IDF
- LangGraph agent con validación

## Ejercicios
1. Implementar búsqueda simple
2. Agregar ranking por relevancia
3. Construir agente completo con validación
