# Ejercicio 1: Servidor MCP mínimo

## 🎯 Objetivo
Construir un servidor MCP esqueleto que responda correctamente a `initialize` y `tools/list` con formato JSON-RPC 2.0.

## 📋 Descripción
Crea una clase `SimpleMCPServer` con un método `handle(request)` que reciba diccionarios Python simulando requests JSON-RPC. El servidor debe:

- Responder `initialize` con `protocolVersion`, `serverInfo` y `capabilities`.
- Responder `tools/list` con al menos una tool ficticia llamada `ping`.
- Devolver errores JSON-RPC si llega un método desconocido.

No uses librerías externas ni sockets: la meta es entender la forma de los mensajes.

## 💡 Pistas
- Todos los mensajes deben incluir `jsonrpc: "2.0"`.
- Conserva el `id` original en la respuesta.
- Puedes usar un diccionario `handlers` para mapear métodos a funciones.

## ✅ Criterios de Éxito
- `initialize` devuelve un objeto `result` válido.
- `tools/list` devuelve una lista `tools` con nombre, descripción e `inputSchema`.
- Un método no soportado produce `error.code` negativo.

## 🚀 Bonus
Agrega un pequeño script demo que imprima request y response para visualizar el intercambio.
