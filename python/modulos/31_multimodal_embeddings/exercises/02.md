# Ejercicio 2: VectorStore en memoria

## 🎯 Objetivo
Construir un `VectorStore` que soporte `add_document`, `search` y `delete` usando embeddings calculados con stdlib.

## 📋 Descripción
Diseña una estructura en memoria para guardar documentos junto con su representación vectorial. Debe permitir:

- Agregar nuevos documentos.
- Buscar por similitud coseno y devolver top-k.
- Eliminar documentos por id.

La implementación puede recalcular el índice completo en cada búsqueda; la meta es didáctica.

## 💡 Pistas
- Guarda primero el texto original; luego genera embeddings cuando busques.
- Usa un `dict` para relacionar `doc_id -> text`.
- Al borrar, comprueba si el id existe antes de eliminar.

## ✅ Criterios de Éxito
- `add_document` inserta datos correctamente.
- `delete` no deja referencias huérfanas.
- `search` devuelve resultados ordenados por score descendente.

## 🚀 Bonus
Agrega metadata opcional (`topic`, `source`) y permite filtrarla antes del ranking.
