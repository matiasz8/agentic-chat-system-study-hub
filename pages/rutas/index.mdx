# 🛤️ Rutas Interactivas

> 🎯 RUTAS INTERACTIVAS
Caminos guiados: Rápida (1 semana) o Completa (3 semanas).

Aprende Ask Sage **sin distracciones. Solo lo que necesitas.**

## 🎯 Ruta Rápida (6 Temas)

**Funcionalidad rápido.** Ejecuta en 20-30 min cada tema.

Lee → Ejecuta → Modifica → Verifica.

Sin calendario, sin Jupyter. Cada tema es independiente.

**Para:** Necesitas funcionalidad ahora, entendimiento después.

**Estructura:**
1. Setup & Arquitectura
2. LangGraph (los 3 nodos)
3. Identity Forwarding
4. MCP Data Layer
5. Validación & Guardrails
6. Deploy a AWS

[Iniciar Ruta Rápida →
](/rutas/rapida/tema-1-setup)

## 📚 Ruta Completa (12 Módulos)

**Expertise profundo.** 1-2 semanas de estudio dedicado.

Lee en profundidad → Entiende patrones → Experimenta → Dominas.

**Para:** Quieres ser arquitecto experto en Ask Sage.

**Estructura:**
- **Módulos 1-5:** Frontend, LangGraph, State, Nodos, Aristas
- **Módulos 6-8:** Identity Forwarding, MCP, Validación & Cedar
- **Módulos 9-12:** Testing, Observability, Docker, AWS Deploy
