# Ask Sage: MVP (Q&A Agent Médico)

**Ask Sage** es un agente IA que responde preguntas sobre medicamentos y salud usando RAG (Retrieval-Augmented Generation).

Este es tu **proyecto final**: Un sistema completo de A a Z que integra TODO lo aprendido.

---

## 🎯 Qué es Ask Sage?

```
Usuario:  "¿Qué es la Aspirina?"
    │
    ▼
[Agente Ask Sage]
├─ Busca en base de datos médica
├─ Ordena resultados por relevancia
├─ Genera respuesta con citas
└─ Valida información

Respuesta: "La Aspirina es un antiinflamatorio...
           Fuente: American Medical Association"
```

**Tecnologías usadas**:
- 🧠 LangGraph (orquestación)
- 📚 RAG (búsqueda semántica)
- 💾 Vector DB (almacenamiento)
- ☁️ AWS (deployment)
- 🎨 Next.js (frontend)

---

## 📊 Arquitectura

```
Frontend (Next.js)
    │
    ├─> Streaming UI (useChat)
    └─> "¿Qué es la Aspirina?"
         │
         ▼
Backend (LangGraph)
    ├─ State: {question, retrieved_docs, answer}
    ├─ Node 1: Embeddings (convertir pregunta a vector)
    ├─ Node 2: Search (buscar en vector DB)
    ├─ Node 3: Rank (ordenar por relevancia)
    ├─ Node 4: Generate (crear respuesta con LLM)
    └─ Node 5: Validate (validar con fuentes)
         │
         ▼
Vector Database (Chroma/Pinecone)
    └─ 10,000+ documentos médicos
         │
         ▼
Response: "La Aspirina es..."
```

## 💻 Nivel 1: MVP Simple (RAG Básico)

<BasicExample
  code={`from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Chroma
from langchain.chains import RetrievalQA
from langchain.llms import OpenAI

# 1. Crear base de datos vectorial
embeddings = OpenAIEmbeddings()
vectordb = Chroma(
    collection_name="medical_docs",
    embedding_function=embeddings,
    persist_directory="./chroma_db"
)

# 2. Crear retriever
retriever = vectordb.as_retriever(
    search_type="similarity",
    search_kwargs={"k": 3}  # Top 3 resultados
)

# 3. Crear cadena QA
llm = OpenAI(temperature=0)
qa_chain = RetrievalQA.from_chain_type(
    llm=llm,
    chain_type="stuff",
    retriever=retriever
)

# 4. Usar
answer = qa_chain.run("¿Qué es la Aspirina?")
print(answer)
`}

## 💻 Nivel 2: MVP Completo (con Ranking)

<BasicExample
  code={`from langgraph.graph import StateGraph, START, END
from typing import TypedDict, Annotated
from operator import add

class AskSageState(TypedDict):
    question: str
    retrieved_docs: Annotated[list, add]
    ranked_docs: list
    answer: str
    confidence: float

def retrieval_node(state: AskSageState):
    """Busca documentos relevantes"""
    # Simular búsqueda semántica
    results = [
        {"title": "Aspirin Overview", "score": 0.95},
        {"title": "Dosage Guidelines", "score": 0.87},
        {"title": "Side Effects", "score": 0.72}
    ]
    return {"retrieved_docs": results}

def ranking_node(state: AskSageState):
    """Ordena por relevancia"""
    ranked = sorted(
        state['retrieved_docs'],
        key=lambda x: x['score'],
        reverse=True
    )
    return {"ranked_docs": ranked}

def generation_node(state: AskSageState):
    """Genera respuesta con LLM"""
    context = "\\n".join([
        f"- {doc['title']}" 
        for doc in state['ranked_docs'][:3]
    ])
    
    prompt = f"""Based on:
{context}

Answer: {state['question']}"""
    
    # Simular LLM call
    answer = f"La Aspirina es un antiinflamatorio usado para..."
    confidence = 0.92
    
    return {"answer": answer, "confidence": confidence}

# Construir grafo
graph = StateGraph(AskSageState)
graph.add_node("retrieve", retrieval_node)
graph.add_node("rank", ranking_node)
graph.add_node("generate", generation_node)

graph.add_edge(START, "retrieve")
graph.add_edge("retrieve", "rank")
graph.add_edge("rank", "generate")
graph.add_edge("generate", END)

# Ejecutar
compiled = graph.compile()
result = compiled.invoke({
    "question": "¿Qué es la Aspirina?",
    "retrieved_docs": [],
    "ranked_docs": [],
    "answer": "",
    "confidence": 0.0
})
print(f"Answer: {result['answer']}")
print(f"Confidence: {result['confidence']}")
`}

## 💻 Nivel 3: Production (con Validación)

<AdvancedExample
  code={`class ProductionAskSage:
    def __init__(self, vector_db_path: str, api_key: str):
        self.vectordb = self._init_db(vector_db_path)
        self.validator = ResponseValidator()
        self.monitor = MonitoringClient()
    
    def answer_question(self, question: str) -> Dict:
        """Responde pregunta con validación"""
        
        # 1. Retrieve
        relevant_docs = self.vectordb.search(question, top_k=5)
        
        # 2. Rank
        ranked = self._rerank_docs(relevant_docs)
        
        # 3. Generate
        context = self._build_context(ranked)
        answer = self._generate_with_llm(question, context)
        
        # 4. Validate
        is_valid = self.validator.check(
            question=question,
            answer=answer,
            sources=ranked
        )
        
        if not is_valid:
            answer = "I cannot provide a confident answer to this question."
            confidence = 0.0
        else:
            confidence = self._calculate_confidence(ranked)
        
        # 5. Log
        self.monitor.log_query(
            question=question,
            answer=answer,
            confidence=confidence,
            sources=ranked
        )
        
        return {
            "answer": answer,
            "confidence": confidence,
            "sources": ranked,
            "valid": is_valid
        }

# Uso
sage = ProductionAskSage(
    vector_db_path="./medical_db",
    api_key="sk-..."
)

result = sage.answer_question("¿Es segura la Aspirina en embarazo?")
print(result)
`}
