# Manual Vercel Setup

## Opción 1: Usando Vercel Dashboard (Recomendado)

1. Ir a https://vercel.com
2. Click "Add New" → "Project"
3. Importar del repositorio GitHub
4. Seleccionar: matiasz8/agentic-chat-system-study-hub
5. Framework: Next.js (detecta automáticamente)
6. Click Deploy

**URL Final:** `https://agentic-chat-system-study-hub.vercel.app`

## Opción 2: CLI (Si tienes Vercel CLI instalado)

```bash
vercel login
vercel --prod
```

## Lo que Vercel hará automáticamente:
- Detectar Next.js
- Correr: npm install
- Correr: npm run build
- Servir desde .next/
- Auto-deploy en cada push a main

## Environment Variables (si necesitas)
Configure en Vercel Dashboard → Settings → Environment Variables
