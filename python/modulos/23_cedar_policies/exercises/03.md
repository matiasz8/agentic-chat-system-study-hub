# Ejercicio 3: Servicio de autorización con contexto

## 🎯 Objetivo

Crear un motor de autorización más completo inspirado en Cedar.

## 📋 Descripción

Implementa un servicio que evalúe solicitudes con contexto adicional, por ejemplo:

- hora del día;
- rango de IP;
- tenant actual;
- región.

El servicio debe producir una decisión final y un registro de auditoría con las políticas que coincidieron.

## 💡 Pistas

- El módulo `ipaddress` resuelve validación de rangos IP.
- `datetime.strptime` te ayuda con horarios `HH:MM`.
- Separar `EntityGraph`, `PolicyStore` y `AuthorizationService` simplifica el diseño.

## ✅ Criterios de Éxito

- La evaluación usa contexto real.
- Se registran políticas coincidentes.
- `forbid` explícito prevalece.
- Se muestran ejemplos permitidos y denegados.

## 🚀 Bonus

Agrega un campo `reason` y exporta el audit log como JSON.
