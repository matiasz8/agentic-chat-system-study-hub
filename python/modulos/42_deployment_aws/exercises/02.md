# Ejercicio 2: Infraestructura Tipo CDK

## 🎯 Objetivo
Definir una especificación de infraestructura estilo CDK usando `dataclasses` de Python.

## 📋 Descripción
Modela una arquitectura para Ask Sage con componentes como `VPC`, `ECSService`, `RDSInstance` y `ElastiCacheCluster`. La salida final debe poder serializarse a un diccionario o JSON para inspección.

## 💡 Pistas
- Usa `@dataclass` para cada recurso.
- Crea una clase raíz `StackSpec` que agrupe los componentes.
- Incluye campos importantes: subredes, CPU, memoria, engine y réplicas.
- Piensa qué recursos deberían ser públicos y cuáles privados.

## ✅ Criterios de Éxito
- La infraestructura queda representada por tipos claros.
- La salida muestra un stack coherente para Ask Sage.
- Se distinguen networking, compute y data services.
- El ejemplo puede ejecutarse e imprimir la especificación.

## 🚀 Bonus
Agrega tags globales y una bandera de entorno (`dev`, `staging`, `prod`).
