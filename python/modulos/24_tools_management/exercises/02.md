# Ejercicio 2: Validador de esquema propio

## 🎯 Objetivo

Agregar validación de entradas antes de ejecutar una tool.

## 📋 Descripción

Extiende tu registry o executor para validar payloads con un subconjunto pequeño de JSON Schema:

- `type`
- `required`
- `properties`
- `minimum` opcional

Si el payload no cumple, debes devolver un error claro y no ejecutar la tool.

## 💡 Pistas

- Crea un mapa entre tipos de esquema y tipos Python.
- Valida primero presencia de campos requeridos.
- Luego valida tipo y reglas extra por campo.

## ✅ Criterios de Éxito

- Un payload válido ejecuta la tool.
- Un payload inválido falla antes de ejecutar.
- El error menciona el campo problemático.
- El ejemplo imprime casos correctos e incorrectos.

## 🚀 Bonus

Valida también el tipo de salida esperado.
