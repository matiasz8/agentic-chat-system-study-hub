## 📖 Lee

## 🔧 Modifica el Código

Abre: `frontend/pages/api/chat.ts`

Línea ~15, busca:
```typescript
// Mock token
const token = "vendor-mx-123";
```

**Entendimiento:** Este token va al backend. Backend lo valida en `nodo_verificar_identidad()`.

## ⚙️ Ejecuta

Sin cambios aún, pregunta en chat:
```
"¿Datos para MX?"
```

Luego cambia el token a `"vendor-ar-456"` y pregunta:
```
"¿Datos para AR?"
```

**¿Qué ves?** Respuesta diferente = identity forwarding funcionando.

## ✅ Verifica

```bash
# En backend terminal, busca logs:
print(f"Verified identity: {contexto['territorio']}")
```

Debería mostrar "MX" primero, luego "AR".
