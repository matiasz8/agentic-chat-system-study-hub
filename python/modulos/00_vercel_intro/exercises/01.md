# Ejercicio 01 – Básico: Construir un simulador de petición IA

## Objetivo

Implementar una función `llamar_proveedor(nombre, modelo, mensaje)` que simule
el ciclo básico de una llamada al Vercel AI SDK: construir los mensajes,
enviarlos al proveedor y devolver la respuesta con metadatos de uso.

---

## Descripción

En el Vercel AI SDK, el flujo básico es:

```typescript
const result = await generateText({
  model: openai("gpt-4o"),
  messages: [{ role: "user", content: "..." }],
});
console.log(result.text);
```

Tu tarea es replicar esa idea en Python puro, sin librerías externas.

---

## Requisitos

1. Crear una clase `Proveedor` con atributos `nombre` y `modelo`.
2. Crear una función `llamar_proveedor(proveedor, mensaje_usuario)` que:
   - Construya la lista de mensajes con rol `"sistema"` y `"usuario"`.
   - Simule la llamada (retardo de 50 ms con `time.sleep`).
   - Devuelva un diccionario con `texto`, `tokens_entrada`, `tokens_salida`.
3. Imprimir la respuesta en formato legible.

---

## Pistas

- Usa `time.sleep(0.05)` para simular latencia.
- `tokens_entrada` puede ser `len(mensaje.split())`.
- El texto de respuesta puede ser cualquier string descriptivo.

---

## Criterios de éxito

- [ ] La función devuelve un `dict` con las tres claves requeridas.
- [ ] El programa imprime el texto de respuesta sin errores.
- [ ] El código es ejecutable con `python3 solutions/01.py`.
