# Ejercicio 2: Tools reales con tools/call

## 🎯 Objetivo
Extender el servidor para soportar `tools/call` con herramientas útiles y validación básica de argumentos.

## 📋 Descripción
Implementa tres tools reales:

1. `calculator(expression)` para operaciones aritméticas.
2. `string_transform(text, operation)` para transformar cadenas.
3. `datetime_info(timezone_offset)` para obtener fecha y hora aproximadas.

El servidor debe descubrirlas con `tools/list` y ejecutarlas con `tools/call`. Maneja errores como tool inexistente, argumentos faltantes u operaciones no válidas.

## 💡 Pistas
- Para `calculator`, evita `eval`; usa `ast`.
- Para `datetime_info`, `datetime` de stdlib es suficiente.
- `string_transform` puede soportar `upper`, `lower`, `title` y `reverse`.

## ✅ Criterios de Éxito
- Las tres tools aparecen en `tools/list`.
- `tools/call` produce `result.content` con texto útil.
- Los errores son legibles y no rompen el servidor.

## 🚀 Bonus
Agrega una cuarta tool `slugify` usando solo operaciones de cadena y `re`.
