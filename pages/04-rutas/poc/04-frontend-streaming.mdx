# 04. Frontend + Streaming (2 horas)

> Conectar React + Vercel AI SDK.

## 🎯 Objetivo

Crear interfaz que:
1. Envía mensajes al backend
2. Recibe stream de tokens
3. Renderiza en tiempo real

---

## 💻 Código

```tsx
// frontend/components/ChatBox.tsx
"use client";

import { useChat } from "ai/react";

export default function ChatBox() {
  const { messages, input, handleInputChange, handleSubmit } = useChat({
    api: "/api/chat"
  });

  return (
    <div className="w-full max-w-md">
      <div className="space-y-4 mb-4">
        {messages.map((msg) => (
          <div
            key={msg.id}
            className={msg.role === "user" ? "text-right" : "text-left"}
          >
            <p className="inline-block p-2 rounded bg-gray-200">
              {msg.content}
            </p>
          </div>
        ))}
      </div>

      <form onSubmit={handleSubmit} className="flex gap-2">
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Escribe algo..."
          className="flex-1 p-2 border rounded"
        />
        <button type="submit" className="p-2 bg-blue-500 text-white rounded">
          Enviar
        </button>
      </form>
    </div>
  );
}
```
