# 🎯 Tema 1: Setup & Arquitectura

> TEMA 1: SETUP
Configura el entorno en 30 min.

**Qué aprenderás:** Cómo funciona Ask Sage end-to-end. 2 minutos.

## 📖 Lee

- [Ask Sage MVP](/proyectos/40-ask-sage-mvp)
- Entender: Frontend → Backend → LangGraph → Respuesta

## ⚙️ Ejecuta

```bash
cd ask-sage-starter
npm install
npm run backend  # Terminal 1
```

```bash
# Terminal 2
npm run dev
# Abre http://localhost:3000
```

¿Ves el chat? Pregunta: "¿Dosis para insuficiencia renal?"
