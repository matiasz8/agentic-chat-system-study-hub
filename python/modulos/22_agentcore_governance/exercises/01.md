# Ejercicio 1: AgentRegistry básico

## 🎯 Objetivo

Construir un registro simple de agentes que centralice metadata operativa.

## 📋 Descripción

Implementa una clase `AgentRegistry` que permita guardar agentes con estos campos:

- `name`
- `capabilities`
- `owner`
- `status`

El registro debe permitir dar de alta agentes, consultarlos por `agent_id` y listar cuáles pueden ejecutar una capacidad específica.

## 💡 Pistas

- Un diccionario `agent_id -> metadata` alcanza para empezar.
- Puedes usar `dataclasses.dataclass` para modelar cada agente.
- Piensa en `status` como `active`, `disabled` o `maintenance`.

## ✅ Criterios de Éxito

- Puedes registrar al menos dos agentes.
- Puedes consultar uno por `agent_id`.
- Puedes filtrar por capacidad.
- El programa imprime una vista resumen sin errores.

## 🚀 Bonus

Agrega validación para evitar IDs duplicados y una función que liste solo agentes activos.
