# Ejercicio 1: Aislamiento por Tenant

## 🎯 Objetivo
Implementar un almacén documental donde cada consulta quede estrictamente limitada a un tenant.

## 📋 Descripción
Crea una clase `TenantIsolationStore` con métodos para agregar documentos y buscar por `tenant_id`. Una consulta del tenant `acme` jamás debe devolver documentos de `globex`.

## 💡 Pistas
- Guarda los documentos en un diccionario indexado por tenant.
- Normaliza tokens de la pregunta.
- Devuelve resultados vacíos cuando el tenant no existe.
- Imprime el tenant consultado para evidenciar el scope.

## ✅ Criterios de Éxito
- Los datos están separados por tenant.
- El resultado solo contiene documentos del tenant solicitado.
- El ejemplo muestra al menos dos tenants distintos.
- El programa puede ejecutarse desde consola con `main()`.

## 🚀 Bonus
Añade un contador de consultas por tenant para preparar métricas de uso.
