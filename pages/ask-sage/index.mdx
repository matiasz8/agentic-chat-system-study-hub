# Ask Sage: Chatbot Farmacéutico Agentic

> Caso de uso específico: Entender cómo implementar un chatbot para validación y consultas farmacéuticas.

## ¿Qué es Ask Sage?

Ask Sage es un chatbot agentic diseñado para:
- ✓ Consultas de medicamentos
- ✓ Validación de interacciones
- ✓ Cumplimiento regulatorio
- ✓ Auditoría de accesos
