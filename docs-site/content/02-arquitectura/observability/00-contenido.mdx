## 📝 1. Logging Estructurado

### Modelo: Structured Logging

```python
import json
import logging
from datetime import datetime
from enum import Enum

class LogLevel(Enum):
    DEBUG = "DEBUG"
    INFO = "INFO"
    WARNING = "WARNING"
    ERROR = "ERROR"
    CRITICAL = "CRITICAL"

class AgentLogger:
    def __init__(self, agent_name: str):
        self.agent_name = agent_name

    def log(self, level: LogLevel, message: str, **context):
        """Log estructurado con contexto"""
        entry = {
            "timestamp": datetime.utcnow().isoformat(),
            "agent": self.agent_name,
            "level": level.value,
            "message": message,
            "context": context
        }
        print(json.dumps(entry))

# Uso
logger = AgentLogger("ask-sage")

logger.log(
    LogLevel.INFO,
    "Patient query received",
    patient_id="P123",
    query="Medication interaction?",
    source="mobile_app"
)

# Output:
# {
#   "timestamp": "2026-06-02T14:30:00.000Z",
#   "agent": "ask-sage",
#   "level": "INFO",
#   "message": "Patient query received",
#   "context": {
#     "patient_id": "P123",
#     "query": "Medication interaction?",
#     "source": "mobile_app"
#   }
# }
```

### Mejores Prácticas

| ✅ BIEN | ❌ MAL |
|--------|--------|
| `log("User login", user_id="U123", method="mfa")` | `log("User login")` |
| Timestamps en UTC ISO 8601 | Timestamps ambiguas |
| Niveles consistentes (INFO, WARN, ERROR) | Mezclar print(), log(), stderr |
| Contexto como diccionario | Concatenar strings |
| `log_level=INFO` en config | Hardcoded log levels |

### Níveis de Logging para Agentes IA

```python
# CRITICAL: Agent down, compliance violation
logger.log(LogLevel.CRITICAL, "Audit log failed", error=str(e))

# ERROR: Action failed, needs intervention
logger.log(LogLevel.ERROR, "LLM invocation failed", reason="rate_limit")

# WARNING: Unexpected but recoverable
logger.log(LogLevel.WARNING, "Cache miss for prompt template")

# INFO: Normal operations
logger.log(LogLevel.INFO, "Decision made", action="prescribe", confidence=0.92)

# DEBUG: Developer info (off in production)
logger.log(LogLevel.DEBUG, "Prompt tokens used", count=2345)
```

## 🔗 2. Distributed Tracing

### OpenTelemetry Setup

```python
from opentelemetry import trace, metrics
from opentelemetry.exporter.jaeger.thrift import JaegerExporter
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor

# Setup Jaeger exporter
jaeger_exporter = JaegerExporter(
    agent_host_name="localhost",
    agent_port=6831,
)

trace.set_tracer_provider(TracerProvider())
trace.get_tracer_provider().add_span_processor(
    BatchSpanProcessor(jaeger_exporter)
)

tracer = trace.get_tracer(__name__)

# Uso
def ask_sage_workflow():
    with tracer.start_as_current_span("patient_query") as span:
        span.set_attribute("patient_id", "P123")

        with tracer.start_as_current_span("validate_request"):
            # Validación
            pass

        with tracer.start_as_current_span("call_llm"):
            # LLM call
            pass

        with tracer.start_as_current_span("audit_log"):
            # Write audit trail
            pass
```

## 📊 3. Métricas

### Tipos de Métricas

```python
from opentelemetry import metrics

meter = metrics.get_meter(__name__)

# Counter: Aumenta monótonamente
requests_total = meter.create_counter(
    name="agent_requests_total",
    description="Total requests processed",
    unit="1"
)

# Gauge: Valor en un punto de tiempo
active_sessions = meter.create_gauge(
    name="agent_sessions_active",
    description="Number of active sessions",
    unit="1"
)

# Histogram: Distribución
query_latency = meter.create_histogram(
    name="agent_query_latency_ms",
    description="Query latency in milliseconds",
    unit="ms"
)

# Uso
requests_total.add(1, {"agent": "ask-sage", "type": "query"})
active_sessions.set(42, {"agent": "ask-sage"})
query_latency.record(245, {"agent": "ask-sage"})
```

## 🔍 4. Profiling

### Identificar Bottlenecks

```python
import cProfile
import pstats
from io import StringIO

def profile_agent_query():
    pr = cProfile.Profile()
    pr.enable()

    # Agent code
    result = ask_sage_agent.query("Is this drug interaction safe?")

    pr.disable()
    s = StringIO()
    ps = pstats.Stats(pr, stream=s).sort_stats('cumulative')
    ps.print_stats(10)  # Top 10
    print(s.getvalue())

# Output:
# ncalls  tottime  cumtime
#     10    0.001    0.234  call_llm
#     50    0.002    0.056  tokenize
#    100    0.001    0.034  validate_drug
#   1000    0.001    0.010  cache_lookup
```

## 🚨 5. Alertas

### Configurar Alertas Críticas

```yaml
# alerts.yaml
groups:
  - name: agent
    rules:
      - alert: AskSageHighErrorRate
        expr: rate(agent_errors_total[5m]) > 0.01
        for: 5m
        annotations:
          summary: "Ask Sage error rate > 1%"
          action: "page_oncall"

      - alert: AskSageAuditLogFailed
        expr: increase(audit_log_failures_total[1m]) > 0
        for: 1m
        annotations:
          summary: "Audit logging failed (HIPAA violation)"
          action: "page_compliance_officer_immediately"

      - alert: AskSageLowCacheHitRate
        expr: rate(cache_hits_total[5m]) / rate(cache_requests_total[5m]) < 0.7
        for: 15m
        annotations:
          summary: "Cache hit rate < 70%"
          action: "investigate"
```
