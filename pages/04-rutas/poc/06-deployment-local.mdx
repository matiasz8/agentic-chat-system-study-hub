# 06. Deployment Local (1 hora)

> Docker Compose local.

## 🎯 Objetivo

Correr todo en Docker:
- Frontend (Next.js)
- Backend (FastAPI)
- Todo conectado

---

## 📝 docker-compose.yml

```yaml
version: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    environment:
      - PYTHONUNBUFFERED=1
    command: uvicorn main:app --host 0.0.0.0 --port 8000

  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    environment:
      - NEXT_PUBLIC_API_URL=http://localhost:8000
    depends_on:
      - backend
```

---

## ✅ Ejecutar

```bash
docker-compose up

# Verifica en:
# Frontend: http://localhost:3000
# Backend: http://localhost:8000/docs
```
