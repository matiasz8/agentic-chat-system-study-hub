# Ejercicio 01 — Aristas rectas

Modela un pipeline fijo con tres nodos: `collect`, `transform` y `store`.

## Requisitos
- Usa un `TypedDict` para el state.
- Cada nodo debe agregar su nombre a `steps`.
- El resultado final debe quedar almacenado con un prefijo `STORED::`.
