# 1. Encryption in Transit
SECURESSL = True

### 21 CFR Part 11 (FDA)

```python
# 1. System Validation
# → Documentar diseño, testing, deployment
# → FDA-approved testing protocols

# 2. Electronic Signatures
# → Cada acción requiere user_id + timestamp
# → No se puede repudiar (audit trail)

# 3. Data Integrity
# → Checksums en todos los registros
# → Change logs obligatorios

# 4. System Security
# → Strong authentication (2FA mínimo)
# → Role-based access control (RBAC)
# → Segregation of duties

from enum import Enum

class PharmaceuticalRole(Enum):
    PHARMACIST = "pharmacist"  # Lee/escribe pacientes
    PHARMACIST_MANAGER = "pharmacist_manager"  # Auditoría
    COMPLIANCE_OFFICER = "compliance_officer"  # Reportes
    ADMIN = "admin"  # Sistema

# Cada rol tiene permisos específicos
ROLE_PERMISSIONS = {
    "pharmacist": ["read_patient_data", "write_treatment"],
    "pharmacist_manager": ["read_all_data", "approve_treatments"],
    "compliance_officer": ["read_audit_logs", "export_reports"],
}
```

## 📋 Deployment Checklist

### Fase 1: Pre-deployment (2 semanas antes)

- [ ] **Compliance Audit**: 3rd party auditor revisa arquitectura
- [ ] **Data Migration**: De staging a producción (con backup)
- [ ] **Security Review**: Penetration testing
- [ ] **Load Testing**: Simular 1000 usuarios concurrentes
- [ ] **Disaster Recovery**: Testear restore desde backup

```bash
# Security scan
aws ecr start-image-scan \
  --repository-name ask-sage \
  --image-id imageTag=latest
```

### Fase 2: Deployment (día 1)

```bash
# 1. Backup everything
aws rds create-db-snapshot \
  --db-instance-identifier ask-sage-pharma \
  --db-snapshot-identifier ask-sage-pharma-pre-prod-$(date +%s)

# 2. Deploy to staging first
aws ecs update-service \
  --cluster ask-sage-staging \
  --service ask-sage-api \
  --force-new-deployment

# 3. Run smoke tests
pytest tests/smoke_tests.py -v

# 4. Deploy to production (blue-green)
aws ecs update-service \
  --cluster ask-sage-prod \
  --service ask-sage-api \
  --task-definition ask-sage-prod:NEW_VERSION \
  --deployment-configuration maximumPercent=200,minimumHealthyPercent=100

# 5. Monitor
watch -n 1 "aws ecs describe-services --cluster ask-sage-prod --services ask-sage-api"
```

### Fase 3: Post-deployment (7 días)

- [ ] **Monitoring**: CloudWatch, DataDog alertas OK
- [ ] **Compliance Validation**: Auditor valida compliance
- [ ] **User Acceptance Testing**: Farmacéuticos testan
- [ ] **Performance Validation**: P95 latency < 1s

## 🎯 AgentCore Integration

```python
# Ask Sage se registra en AWS AgentCore
from aws_agentcore import register_agent

agent_config = {
    "name": "ask-sage-pharma",
    "version": "1.0.0",
    "governance_tags": {
        "compliance": "HIPAA,21CFR11",
        "data_classification": "RESTRICTED",
        "owner": "pharma-team"
    },
    "permissions": {
        "database": ["read", "write"],
        "llm": ["invoke"],
        "s3": ["write_logs"]
    },
    "audit_required": True,
    "approval_workflow": "pharmacist_manager"
}

register_agent(agent_config)
```

## 📊 Rollback Procedure

```bash
#!/bin/bash
# rollback.sh - Rollback rápido en emergencia

PREVIOUS_VERSION=$(aws ecs describe-task-definition \
  --task-definition ask-sage-prod:$(($CURRENT_TASK_DEFINITION-1)) \
  --query 'taskDefinition.revision' \
  --output text)

echo "⚠️ Rolling back a versión $PREVIOUS_VERSION"

aws ecs update-service \
  --cluster ask-sage-prod \
  --service ask-sage-api \
  --task-definition ask-sage-prod:$PREVIOUS_VERSION \
  --force-new-deployment

# Esperar a que health checks pasen
sleep 30
aws ecs describe-services --cluster ask-sage-prod --services ask-sage-api \
  --query 'services[0].deployments[0].status'
```
