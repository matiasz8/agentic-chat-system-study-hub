# Ejercicio 01 — FileCheckpoint

Implementa una clase `FileCheckpoint` que guarde y restaure un `TypedDict` usando JSON.

## Requisitos
- Debe aceptar un `Path` al inicializarse.
- Tiene que exponer `save(state)` y `load()`.
- El script debe limpiar el archivo generado al terminar.
