# Introducción a Ask Sage

Ask Sage es un agente de IA que responde consultas sobre medicamentos, interacciones y cumplimiento regulatorio.

## Características clave

- 🔍 **Búsqueda de Medicamentos**: Query sobre propiedades farmacéuticas
- ⚠️ **Detección de Interacciones**: Alertas sobre conflictos de medicamentos
- 📋 **Auditoría**: Registro completo de todas las consultas
- 🔐 **Identity Forwarding**: Autenticación y autorización con AWS
