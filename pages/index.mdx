# 📚 Agentic Chat System Study Hub

> Hub de estudio universitario: Arquitectura de sistemas agentic para Ask Sage.  
> De conceptos fundamentales a producción en AWS AgentCore.

---

## 🎓 ¿Qué es este Hub?

Una **referencia técnica educativa completa** sobre cómo construir sistemas agentic como Ask Sage. Incluye:

- 📖 **Explicaciones profundas** (por qué, cómo, para qué)
- 💡 **Ejemplos prácticos** (código real, diagramas)
- 🧪 **Ejercicios interactivos** (32+ ejercicios con soluciones)
- 🔬 **Validación y testing** (cómo verificar que funciona)
- 📋 **Historias y contexto** (por qué Ask Sage existe)

**No es un POC ejecutable**. Es educación → referencia → guía.

## 📚 Filosofía del Hub

Este hub sigue 5 principios:

1. **Explicación primero**: Entiende el POR QUÉ antes de cómo
2. **Ejemplos siempre**: Todo concepto tiene ejemplo de código
3. **Ejercicios prácticos**: Aprende haciendo
4. **Contexto histórico**: Entiende decisiones arquitectónicas
5. **Ask Sage específico**: Todos los ejemplos son para Ask Sage o generalizable
