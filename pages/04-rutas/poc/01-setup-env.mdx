# 01. Setup Environment (2 horas)

> Instala todo lo que necesitas: Docker, Python, Node.js, dependencias.

## ✅ Checklist de Instalación

### 1. Verificar Python (30 min)

```bash
python --version
# Debe ser 3.9+

# Crear virtual environment
python -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

# Upgradear pip
pip install --upgrade pip
```

### 2. Verificar Node.js (30 min)

```bash
node --version
npm --version
# Ambos deben existir
```

### 3. Verificar Docker (30 min)

```bash
docker --version
docker-compose --version

# Verificar que Docker está corriendo
docker ps
```

### 4. Clonar Repositorio (15 min)

```bash
git clone https://github.com/matiasz8/ask-sage-starter.git
cd ask-sage-starter
```

### 5. Instalar Dependencias Backend (15 min)

```bash
# En carpeta backend/
cd backend
pip install -r requirements.txt
```

### 6. Instalar Dependencias Frontend (15 min)

```bash
# En carpeta frontend/
cd ../frontend
npm install
```
