# 🟡 Ruta POC: Aprende Haciendo

> 16 horas de paso-a-paso. Salida: POC ejecutable en local.

Bienvenido a la **Ruta POC**. Aquí aprenderás **haciendo**.

Cada módulo toma 1-3 horas. Al final tendrás un **chatbot agentic funcionando en tu máquina local** con Docker.

---

## 📋 Estructura de la Ruta

```
00. Que es POC?          ← Estás aquí (5 min)
01. Setup (2h)           ← Instala todo
02. Aprender (3h)        ← Estudia LangGraph
03. Implementar (2h)     ← Crea primer grafo
04. Frontend (2h)        ← UI + streaming
05. Testing (2h)         ← Valida tu código
06. Deploy Local (1h)    ← Docker Compose
07. Validación (1h)      ← Checklist final

TOTAL: 16 horas (puede ser menos si ya sabes Python)
```

---

## 🎯 Objetivo

**Inicio**: "¿Cómo construyo un sistema agentic?"

**Fin**: "Tengo un chatbot agentic corriendo localmente + entiendo cómo deployar"

---

## ✅ Prerrequisitos

- Python 3.9+ instalado
- Node.js 18+ instalado
- Docker + Docker Compose
- Básicos de Python + JavaScript
- VSCode o editor similar
- 16 horas libres (o 2 days)

Si te falta algo, la Sección 01 te ayuda.

---

## 📊 Qué Construiremos

Un **Ask Sage Starter** (versión simplificada de Ask Sage):

```
Frontend (Next.js)
  ↓ POST /api/chat
Backend (FastAPI + Python)
  ├─ Orquestación: LangGraph
  │  ├─ Nodo: verify_identity
  │  ├─ Nodo: search_mcp
  │  └─ Nodo: validate_response
  ├─ Tools: 3 herramientas simples
  └─ Persistencia: Checkpoints
```

**Características**:
✓ Chat interface bonita  
✓ Streaming de respuestas  
✓ Validación de identidad  
✓ Búsqueda simulada  
✓ Testing incluido  
✓ Docker local
