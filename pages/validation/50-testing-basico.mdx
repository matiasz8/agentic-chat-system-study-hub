# Testing de Prompts - Básico

## Objetivo
Aprender a validar salidas de prompts con assertions simples.

## Contenido

### Nivel 1: Assertions
```python
def validate_output(output, expected):
    assert output == expected
    return True

validate_output("Hello", "Hello")  # ✅
```

### Ejercicios
1. Crear validador simple
2. Agregar múltiples assertions
3. Manejar errores
