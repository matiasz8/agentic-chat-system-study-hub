## Contenido

### Conceptos Clave

1. **Deployment en AWS (Amazon Web Services)** - Estrategia de publicación en infraestructura cloud. Involucra elegir servicios (EC2, Lambda, RDS, S3, API Gateway) que escalen automáticamente según demanda. Permite que aplicaciones de agentes alcancen millones de usuarios sin caer.

2. **Containerización con Docker** - Empaquetamiento de la aplicación completa (código + dependencias + runtime) en un contenedor. Garantiza que el agente funcione igual en desarrollo, staging y producción. Base para despliegues reproducibles en AWS ECS, EKS o Kubernetes.

3. **Infrastructure as Code (IaC)** - Definición de infraestructura (servidores, bases de datos, firewalls) en código (Terraform, CloudFormation). Versiona la infraestructura como si fuera código. Permite reproducir ambientes completos con un comando, crítico para DevOps profesional.
