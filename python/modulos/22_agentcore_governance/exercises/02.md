# Ejercicio 2: AuditLogger para tools

## 🎯 Objetivo

Registrar de forma estructurada cada invocación de herramienta hecha por un agente.

## 📋 Descripción

Crea una clase `AuditLogger` que envuelva una función cualquiera y guarde un registro con:

- timestamp
- agent_id
- tool_name
- inputs
- output
- success
- error opcional

Haz una demo con una tool que funcione y otra que falle.

## 💡 Pistas

- Usa `datetime.now()` para el timestamp.
- Guarda los registros en una lista de dataclasses o diccionarios.
- Un bloque `try/except` te permite capturar errores sin perder el audit trail.

## ✅ Criterios de Éxito

- Toda invocación deja un registro.
- Los errores quedan auditados.
- Se puede imprimir el historial en formato legible.
- El ejemplo corre solo con stdlib.

## 🚀 Bonus

Exporta el audit trail a JSON y agrega un campo `duration_ms`.
