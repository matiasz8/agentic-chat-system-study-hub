# Ejercicio 02 — ValidationRouter

Crea una función router que inspeccione `payload` y `score` para elegir entre:

- `process`
- `manual_review`
- `reject`

## Requisitos
- Debe usarse `Literal` para declarar las rutas posibles.
- Debe ejecutarse el handler correcto para cada caso.
- Incluye al menos tres escenarios de prueba.
