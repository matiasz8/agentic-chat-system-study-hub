## 📖 PRIORIDAD 1: FRONTEND (Días 1-3)

### ¿Por qué primero?
Ask Sage necesita **UX fluida**. Los vendedores esperan respuestas en tiempo real.

### 📚 Módulos en orden

| Orden | Módulo | Concepto Clave | Tiempo |
|-------|--------|---|--------|
| 1️⃣ | [00-vercel-intro](/02-arquitectura/frontend/00-vercel-intro) | Cómo funciona Vercel AI SDK | 30 min |

### 🎓 Ejemplo Ask Sage: Streaming

**Escenario**: Vendedor pregunta "¿Dosis para pacientes con insuficiencia renal?"

```
Vendedor escribe pregunta
        ↓
Bot comienza a responder (token 1)
"Por favor espere mientras búsco..."
        ↓
Bot consulta base de datos
"Encontré 3 opciones..."
        ↓
Bot procesa información
"La recomendada es..."
```

**Sin streaming**: vendedor espera 3 segundos en blanco ❌  
**Con streaming**: ve cada palabra llegar en tiempo real ✅

### ¿Por qué tercero?
**CRÍTICO para Ask Sage**: Un vendedor de MX NO puede ver productos de AR. Identity Forwarding es la barrera de seguridad.

| Orden | Módulo | Concepto Clave | Tiempo |

| 2️⃣ | [21-identity-forwarding](/02-arquitectura/runtime/21-identity-forwarding) | **⭐ CRÍTICO**: Pasar token Okta del vendedor de punta a punta | 90 min |
| 3️⃣ | [22-agentcore-governance](/02-arquitectura/runtime/22-agentcore-governance) | Runtime seguro (qué puede hacer el bot) | 60 min |

### 🎓 Ejemplo Ask Sage: Identity Forwarding

**Escenario**:
```
Vendedor MÉXICO (token: Okta_MX_V001)
        ↓
Pregunta llega a Ask Sage
        ↓
Identity Forwarding verifica: "V001 tiene acceso a qué?"
        ↓
Consulta a base de datos:
SELECT productos FROM vendedor_acceso 
WHERE vendedor_id = 'V001' AND territorio = 'MX'
        ↓
Bot solo ve esos productos
        ↓
Respuesta: "Tenemos 3 opciones para MX"
        ↓
Vendedor ARGENTINA NO vería esa lista
```

## 💬 Dudas Frecuentes

**P: ¿Puedo saltarme Orchestration?**  
R: No. Ask Sage necesita LangGraph para lógica de decisión. Sin eso, es solo un chatbot genérico.

**P: ¿Y si no entiendo Identity Forwarding?**  
R: CRÍTICO. Es la diferencia entre: "Todos ven todo" vs. "Cada vendedor solo ve sus datos". Dedica 90 minutos.

**P: ¿Puedo hacer Data antes que Runtime?**  
R: No. Primero asegura el acceso (Runtime), luego trae datos (Data).
