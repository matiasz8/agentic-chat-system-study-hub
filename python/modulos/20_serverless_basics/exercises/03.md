# Ejercicio 03 – Avanzado: Cola de trabajo con reintentos y DLQ

## Objetivo

Implementar una cola de trabajo con política de reintentos (backoff
exponencial) y una Dead-Letter Queue (DLQ) para mensajes que fallaron
demasiadas veces.

---

## Descripción

En AWS, una cola SQS puede configurarse para reintentar mensajes fallidos
y mover a DLQ los que superan el máximo de intentos:

```
Cola SQS → Worker procesa → Falla → Reintento (backoff)
                         → Falla → Reintento (backoff)
                         → Falla → Mueve a DLQ
```

---

## Requisitos

1. Clase `Mensaje` con: `id`, `cuerpo`, `intentos`, `max_intentos`.
2. Clase `Cola` con: `enviar`, `recibir`, `reencolar`, `enviar_dlq`.
3. Función `procesar(mensaje) -> bool` que falle ~50% del tiempo
   (`random.random() < 0.5` lanza `RuntimeError`).
4. Función `worker(cola)` que:
   - Reciba mensajes mientras haya en la cola.
   - Reintente con `time.sleep` exponencial si falla.
   - Envíe a DLQ si se supera `max_intentos`.
5. Al final, imprimir cuántos mensajes se procesaron OK vs. en DLQ.

---

## Pistas

- `backoff = 0.02 * (2 ** intentos)` es el backoff exponencial básico.
- `collections.deque` es ideal para la cola (FIFO eficiente).
- Usar `random.seed(42)` al inicio para resultados reproducibles.

---

## Criterios de éxito

- [ ] Mensajes que fallan se reencolan hasta `max_intentos`.
- [ ] Mensajes que superan `max_intentos` aparecen en DLQ.
- [ ] El código es ejecutable con `python3 solutions/03.py`.
