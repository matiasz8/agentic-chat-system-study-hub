## ⚙️ Local Docker (primero)

```bash
cd ask-sage-starter

# Build & run con Docker Compose
docker compose up

# Verifica:
# - Frontend: http://localhost:3000
# - Backend: http://localhost:8000/health
```

## 🔧 Checklist Pre-Deploy

Antes de AWS, tu app debe:

- [ ] Todo funciona localmente
- [ ] Tests pasan
- [ ] Variables de ambiente configuradas
- [ ] Logs en stdout (no archivos)

## 📋 Deploy a AWS ECS

1. **Build images:**
```bash
docker build -t ask-sage-frontend ./frontend
docker build -t ask-sage-backend ./backend
```

2. **Push a ECR:**
```bash
aws ecr get-login-password | docker login --username AWS --password-stdin <account>.dkr.ecr.us-east-1.amazonaws.com
docker tag ask-sage-frontend:latest <account>.dkr.ecr.us-east-1.amazonaws.com/ask-sage-frontend:latest
docker push <account>.dkr.ecr.us-east-1.amazonaws.com/ask-sage-frontend:latest
```

3. **Deploy ECS task:**
```bash
aws ecs update-service --cluster ask-sage --service frontend --force-new-deployment
```
