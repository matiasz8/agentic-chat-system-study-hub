# El State (Estado Centralizado) en LangGraph

El **State** es la memoria compartida de tu agente. Todo viaja por aquí: mensajes, contexto, resultados, errores.

Piénsalo así: Si tu agente es un cerebro, el State es la sangre. 🧠💉

---

## 🔄 ¿Qué es el State?

```
┌──────────────────────────────────────────┐
│        STATE (Diccionario Python)        │
├──────────────────────────────────────────┤
│ {                                        │
│   "messages": ["Hola", "Mundo"],         │
│   "current_step": "processing",          │
│   "user_id": "user_123",                 │
│   "results": [],                         │
│   "errors": []                           │
│ }                                        │
└──────────┬────────────────────┬──────────┘
           │                    │
      ┌────▼───┐           ┌────▼──┐
      │ Node 1 │           │ Node 2│
      │ (LEER) │           │ (LEER)│
      └────┬───┘           └────┬──┘
           │ (actualiza)      │ (actualiza)
           └────────┬─────────┘
                    │
           ┌────────▼─────────┐
           │ State Actualizado│
           │ (persistencia)   │
           └──────────────────┘
```

### 3 Principios

✅ **Centralizado**: Un único punto de verdad  
✅ **Inmutable**: Cada cambio crea nuevo estado  
✅ **Tipado**: Defines explícitamente qué contiene

## 💻 Nivel 1: State Básico

El form más simple es un **TypedDict**:

<BasicExample 
  code={`from typing import TypedDict

class SimpleState(TypedDict):
    """Estado mínimo para un agente"""
    messages: list[str]      # Historial de mensajes
    current_step: str        # Paso actual ("validation", "processing", etc)

# Uso:
state = {"messages": ["Hola"], "current_step": "inicio"}
`}
  title="01_state_basico.py"
/>

**Cuándo usar**: Prototipos rápidos, demos, desarrollo local

## 💻 Nivel 2: State Intermedio (Con Reducers)

Cuando necesitas **control granular** sobre cómo se actualiza cada campo:

<AdvancedExample
  code={`from typing import TypedDict, Annotated
from operator import add

class AgentState(TypedDict):
    """State con múltiples campos y reducers"""
    messages: Annotated[list, add]        # ✅ Acumula (concatena)
    current_step: str                     # Reemplaza valor
    context: dict                         # Reemplaza diccionario
    results: Annotated[list, add]         # ✅ Acumula
    conversation_id: str                  # ID único

# El reducer 'add' = concatena/acumula
# Sin reducer = reemplaza valor

# Ejemplo de uso:
from langgraph.graph import StateGraph, START, END

def node_1(state: AgentState):
    # Retorna qué campos actualizar
    return {
        "messages": ["Node 1 ejecutado"],  # Se suma a la lista existente
        "current_step": "processing"       # Se reemplaza
    }

graph = StateGraph(AgentState)
graph.add_node("node1", node_1)
graph.add_edge(START, "node1")
`}
  title="02_state_con_reducers.py"
/>

**Ventaja**: Control preciso de cómo se actualizan datos  
**Cuándo usar**: Agentes con múltiples nodos, conversaciones, históricos

## 💻 Nivel 3: State Avanzado (Custom Reducers)

Para casos complejos, define **reducers personalizados**:

<AdvancedExample
  code={`from typing import TypedDict, Annotated

def merge_context(existing: dict, update: dict) -> dict:
    """Merge inteligente de contextos"""
    merged = existing.copy() if existing else {}
    merged.update(update)
    return merged

def deduplicate_errors(existing: list, new_errors: list) -> list:
    """Acumula errores pero elimina duplicados"""
    seen = set()
    result = []
    for error in (existing or []) + new_errors:
        error_str = str(error)
        if error_str not in seen:
            seen.add(error_str)
            result.append(error)
    return result

class AdvancedState(TypedDict):
    messages: Annotated[list, add]
    context: Annotated[dict, merge_context]
    errors: Annotated[list, deduplicate_errors]
    metadata: Annotated[dict, merge_context]

# Ahora cuando actualizas:
# - context se hace merge (no reemplaza)
# - errors se acumula pero sin duplicados
# - metadata se combina inteligentemente
`}
  title="03_state_advanced_reducers.py"
/>

**Cuándo usar**: Producción, agentes con requisitos de seguridad/compliance

## 🚀 Quick Start: Tu Primer State

### 1. Define el State

<BasicExample
  code={`from typing import TypedDict, Annotated
from operator import add

class MyState(TypedDict):
    user_input: str
    messages: Annotated[list, add]
    result: str
`}
  title="step_1_define_state.py"
/>

### 2. Crea un nodo que lo use

<BasicExample
  code={`def process_node(state: MyState):
    # Lee del state
    user_msg = state['user_input']
    
    # Procesa
    result = f"Procesando: {user_msg}"
    
    # Actualiza state
    return {
        "messages": [f"[process_node]: {result}"],
        "result": result
    }
`}
  title="step_2_crear_nodo.py"
/>

### 3. Construye el grafo

<BasicExample
  code={`from langgraph.graph import StateGraph, START, END

graph = StateGraph(MyState)
graph.add_node("process", process_node)
graph.add_edge(START, "process")
graph.add_edge("process", END)

# Compila y ejecuta
compiled = graph.compile()
result = compiled.invoke({
    "user_input": "Hola agente",
    "messages": [],
    "result": ""
})

print(result["messages"])  # ["[process_node]: Procesando: Hola agente"]
`}
  title="step_3_compilar.py"
/>

    user_message: str

    mode: Literal["chat", "search"]     # Modo actual

`}
  title="ejemplo_1_chatbot.py"
/>

### Ejemplo 2: Workflow de Validación

<BasicExample
  code={`class ValidationState(TypedDict):
    input_data: dict
    validation_errors: Annotated[list, deduplicate_errors]
    step: str  # "receive" → "validate" → "process" → "done"
    attempts: Annotated[int, add]  # Cuenta intentos
    
# Flujo:
# Paso 1 (receive): 0 errores
# Paso 2 (validate): encontramos 3 errores → validation_errors = [e1, e2, e3]
# Paso 3 (validate retry): encontramos 2 errores más → 5 total
# Reducer evita duplicados, así no tenemos [e1, e2, e3, e1, e2, e3, e4, e5]
`}
