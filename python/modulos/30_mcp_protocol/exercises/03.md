# Ejercicio 3: Cliente MCP con descubrimiento

## 🎯 Objetivo
Construir un cliente MCP que descubra herramientas disponibles, permita invocarlas y maneje errores de forma elegante.

## 📋 Descripción
Implementa un cliente que se conecte a un servidor MCP en memoria. El flujo sugerido es:

1. Ejecutar `initialize`.
2. Ejecutar `tools/list` y mostrar el catálogo.
3. Permitir invocar tools con argumentos definidos por el usuario o por un menú preconfigurado.
4. Mostrar errores JSON-RPC sin crashear el programa.

Tu cliente no necesita transporte real; basta con llamar métodos Python y tratarlo como si fuera un server remoto.

## 💡 Pistas
- Encapsula el envío de requests en un método `send(method, params=None)`.
- Conviene tener un contador incremental de `id`.
- Convierte errores del servidor en mensajes amigables para consola.

## ✅ Criterios de Éxito
- El cliente descubre tools antes de invocarlas.
- Al menos una llamada exitosa y una fallida quedan demostradas.
- La salida explica claramente qué ocurrió en cada paso.

## 🚀 Bonus
Guarda el catálogo de tools en caché y evita pedir `tools/list` más de una vez.
