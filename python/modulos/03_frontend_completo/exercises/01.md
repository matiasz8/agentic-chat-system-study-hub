# Ejercicio 1: Gestor de Sesión de Chat

## 🎯 Objetivo
Construir un administrador simple de sesión que guarde historial de mensajes y permita limpiarlo.

## 📋 Descripción
Implementa una clase `ChatSessionManager` con tres operaciones mínimas: `add_message(role, content)`, `get_history()` y `clear()`. Guarda los mensajes en memoria y devuelve el historial en un formato fácil de inspeccionar.

Este ejercicio representa la capa mínima que necesita una UI de chat antes de agregar streaming o herramientas.

## 💡 Pistas
- Puedes usar una lista de diccionarios o `dataclasses`.
- `get_history()` puede devolver la lista completa o una versión serializada.
- `clear()` debe dejar la sesión en estado inicial.
- Prueba con mensajes de `user` y `assistant`.

## ✅ Criterios de Éxito
- La clase soporta agregar mensajes.
- El historial se puede consultar correctamente.
- `clear()` vacía la sesión.
- El script tiene `main()` y demuestra el comportamiento.

## 🚀 Bonus
Agrega contador de turnos o timestamps por mensaje usando solo stdlib.
