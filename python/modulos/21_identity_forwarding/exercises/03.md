# Ejercicio 03 – Avanzado: Registro de auditoría y motor de políticas

## Objetivo

Construir un motor de políticas tipo Cedar (lista de reglas) y un registro
de auditoría que capture cada operación con su resultado.

---

## Descripción

AWS Cedar es el lenguaje de políticas usado en AgentCore para control de acceso.
Su principio fundamental es: "denegar por defecto, permitir explícitamente".

En este ejercicio implementas la misma lógica en Python:

```python
POLITICAS = [
    ("farmaceutico", "leer", "stock"),
    ("supervisor",   "escribir", "requisicion"),
    # Todo lo que NO está aquí → denegado
]

esta_autorizado("farmaceutico", "escribir", "requisicion")  # → False
esta_autorizado("supervisor",   "leer",     "stock")        # → False (no en lista)
```

---

## Requisitos

1. Lista `POLITICAS` con tuplas `(rol, accion, recurso)`.
2. Función `esta_autorizado(rol, accion, recurso) -> bool`.
3. Clase `RegistroAuditoria` con método `registrar(usuario, operacion, resultado)`.
4. Decorador `@autorizar(accion, recurso)` que:
   - Llame a `esta_autorizado` con el rol del primer argumento.
   - Registre en auditoría el resultado (`"ok"` o `"denegado"`).
   - Lance `PermissionError` si no está autorizado.
5. Aplicar el decorador a 2-3 funciones de negocio.
6. Imprimir el audit log al final.

---

## Pistas

- El decorador recibe el contexto (con `rol`) como primer argumento de la función.
- Usa `functools.wraps` para preservar el nombre de la función decorada.

---

## Criterios de éxito

- [ ] El audit log contiene todas las operaciones (OK y denegadas).
- [ ] Operaciones no autorizadas lanzan `PermissionError`.
- [ ] El código es ejecutable con `python3 solutions/03.py`.
