## ¿Por Qué?

MCP mock devuelve hardcoded. Realidad: Tienes:
- 500 PDFs de fármacos
- Screenshots de dosis
- Videos de administración

Necesitas indexar todo en embeddings.

## Arquitectura

```
PDFs/Screenshots/Videos
  ↓
Bedrock Multimodal Embeddings
  ↓
Vector DB (Pinecone / Weaviate)
  ↓
MCP Search → Retrieval Augmented (RAG)
```

## Implementa

**Paso 1: Instalar dependencias**

```bash
pip install boto3 pinecone-client PyPDF2
```

**Paso 2: Crear embedding pipeline**

```python
import boto3
import pinecone

bedrock = boto3.client("bedrock-runtime")
pinecone.init(api_key=os.getenv("PINECONE_KEY"))

def indexar_pdfs(folder):
    for pdf in os.listdir(folder):
        texto = extraer_texto(pdf)
        # Multimodal embedding
        embedding = bedrock.invoke_model(
            modelId="amazon.titan-embed-image-v1",
            body=json.dumps({"input_text": texto})
        )["embedding"]
        
        # Guardar en Pinecone
        pinecone.Index("ask-sage").upsert(
            vectors=[(pdf, embedding, {"source": pdf})]
        )
```

**Paso 3: Reemplazar MCP mock**
