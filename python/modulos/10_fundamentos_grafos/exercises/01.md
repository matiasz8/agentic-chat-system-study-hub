# Ejercicio 01 – Básico: Construir un grafo de flujo de agente

## Objetivo

Implementar una clase `GrafoDirigido` que represente el flujo de un agente
mediante nodos y aristas, y pueda mostrar su estructura.

---

## Descripción

En LangGraph, un `StateGraph` conecta nodos (funciones) mediante aristas
(transiciones). El grafo resultante describe todos los caminos posibles
que puede tomar el agente.

---

## Requisitos

1. Clase `GrafoDirigido` con:
   - `agregar_nodo(nombre)`: registra un nodo.
   - `agregar_arista(origen, destino)`: conecta dos nodos.
   - `vecinos(nodo) -> list[str]`: devuelve nodos alcanzables.
   - `mostrar()`: imprime la estructura como `nodo → vecino1, vecino2`.
2. Crear un grafo con al menos 4 nodos que represente un flujo de agente
   (ej. `inicio → clasificar → consultar → responder → fin`).
3. Imprimir los vecinos de al menos 2 nodos.

---

## Pistas

- `defaultdict(list)` de `collections` es ideal para la lista de adyacencia.
- Un nodo terminal tiene una lista de vecinos vacía.

---

## Criterios de éxito

- [ ] El grafo almacena correctamente nodos y aristas.
- [ ] `mostrar()` imprime todos los nodos con sus conexiones.
- [ ] El código es ejecutable con `python3 solutions/01.py`.
