# Reference

Durable material: cheatsheets, glossaries, notes on an external API's behaviour.

The test is whether it will still be correct in six months. A cheatsheet mapping one
technology's idioms onto another belongs here. A note about what you are currently
debugging does not.

If a PoC teaches an unfamiliar technology, a glossary here is usually the highest
value page in the repo — write down every term you had to look up. You will not
remember which ones were unfamiliar once they stop being unfamiliar.
