# Streaming: Respuestas en Tiempo Real

El **streaming** hace que tu chat IA se sienta **instantáneo**. En lugar de esperar a que el LLM termine toda la respuesta, recibes tokens uno por uno, mostrando progreso en tiempo real.

Sin streaming = ⏳ Espera 5 segundos, luego aparece todo  
Con streaming = ⚡ Aparecen caracteres mientras se generan

---

## 🔄 ¿Qué es el Streaming?

```
SIN STREAMING:
┌──────────────────────────────┐
│ Usuario espera...             │
│ (5 segundos...)               │
└──────────────────────────────┘
            │
            ▼
┌──────────────────────────────┐
│ "Hola, soy Claude. Estoy     │
│  aquí para ayudarte..."      │
│ (todo aparece de una)        │
└──────────────────────────────┘

CON STREAMING:
┌──────────────────────────────┐
│ Usuario ve progreso:          │
│ "Hola"                       │
│ "Hola, soy"                  │
│ "Hola, soy Claude"           │
│ (aparece carácter por carácter)
└──────────────────────────────┘
```

**Beneficios**:
✅ Mejor UX (parece más rápido)
✅ Feedback inmediato
✅ Menos percepción de latencia
✅ Profesional (como ChatGPT)

## 💻 Nivel 1: Streaming Básico

<BasicExample
  code={`import { useChat } from 'ai/react';

export function ChatUI() {
  const { messages, input, handleInputChange, handleSubmit } = useChat({
    streamProtocol: 'text',  // Streaming habilitado
  });

  return (
    <div>
      {/* Mensajes se actualizan en tiempo real */}
      {messages.map(msg => (
        <div key={msg.id}>
          {msg.role}: {msg.content}  {/* Aparece carácter por carácter */}
        </div>
      ))}
      
      {/* Input */}
      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Escribe aquí..."
        />
        <button type="submit">Enviar</button>
      </form>
    </div>
  );
}
`}
  title="01_streaming_basico.tsx"
/>

**¿Qué sucede?**
1. Usuario envía mensaje
2. Servidor comienza a generar respuesta
3. Cada token se envía inmediatamente
4. React actualiza la UI en tiempo real
5. Usuario ve progreso ⚡

## 💻 Nivel 2: Streaming Avanzado

<BasicExample
  code={`import { useChat } from 'ai/react';
import { useEffect, useRef } from 'react';

export function AdvancedChat() {
  const { messages, input, handleInputChange, handleSubmit, isLoading } = 
    useChat({
      streamProtocol: 'text',
      onFinish: (message) => {
        console.log('Respuesta completa:', message.content);
      },
    });

  const messagesEndRef = useRef(null);

  // Auto-scroll a los nuevos mensajes
  useEffect(() => {
    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' });
  }, [messages]);

  return (
    <div className="chat-container">
      {/* Indicador de carga */}
      {isLoading && <div className="spinner">Escribiendo...</div>}
      
      {/* Mensajes con streaming */}
      {messages.map(msg => (
        <div key={msg.id} className={msg.role}>
          <p className="message-content">
            {msg.content}
            {/* Cursor intermitente mientras se escribe */}
            {isLoading && msg.role === 'assistant' && <span className="cursor">▌</span>}
          </p>
        </div>
      ))}
      
      <div ref={messagesEndRef} />
      
      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={handleInputChange}
          disabled={isLoading}
          placeholder="Escribe aquí..."
        />
        <button type="submit" disabled={isLoading}>
          {isLoading ? 'Streaming...' : 'Enviar'}
        </button>
      </form>
    </div>
  );
}
`}
  title="02_streaming_avanzado.tsx"
/>

**Mejoras**:
- ✅ Auto-scroll automático
- ✅ Cursor intermitente visual
- ✅ Indicador de carga
- ✅ Callback cuando termina
