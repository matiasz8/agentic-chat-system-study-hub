## 💻 Ahora: Código Mínimo

```python
from langgraph.graph import StateGraph
from pydantic import BaseModel

# 1. Define tu State
class AgentState(BaseModel):
    input: str
    output: str
    step: int

# 2. Define nodos
def node_1(state):
    return {"output": f"Procesé: {state.input}", "step": 1}

# 3. Crea grafo
graph = StateGraph(AgentState)
graph.add_node("process", node_1)
graph.set_entry_point("process")
graph.set_finish_point("process")

# 4. Ejecuta
app = graph.compile()
result = app.invoke({"input": "Hola", "output": "", "step": 0})
print(result)  # output: "Procesé: Hola"
```
