# 🎓 Ejercicio Avanzado 1: Multi-LLM Orchestration

> EJERCICIO 1: MULTI-LLM
Compara modelos en paralelo.

**Después de Módulo 12.** Para cuando quieras ir más allá.

## ¿Por Qué?

En producción, una sola LLM puede fallar o ser subóptima. Ask Sage debería poder:

- Usar Claude para análisis de seguridad
- Usar GPT-4 para dosis complejas
- Usar Bedrock para compliance

Y elegir la mejor respuesta.

## Arquitectura

```
Query → Parallelizar
  ├─ Claude (ask seguridad)
  ├─ GPT-4 (ask dosis)
  └─ Bedrock (ask compliance)
  ↓
Comparar resultados
  ├─ Confianza
  ├─ Consistencia
  └─ Cumplimiento
  ↓
Elegir mejor → Respuesta final
```

## Implementa

**Paso 1: Agregar nodo en LangGraph**

```python
async def nodo_multi_llm(state):
    tasks = [
        llamar_claude(state["query"]),
        llamar_gpt(state["query"]),
        llamar_bedrock(state["query"])
    ]
    resultados = await asyncio.gather(*tasks)
    
    mejor = comparar(resultados)
    return {"respuesta": mejor, "source": mejor["source"]}
```

**Paso 2: Integrar en el grafo**

Después de `nodo_buscar_mcp`, antes de `nodo_validar`:

```python
graph.add_node("multi_llm", nodo_multi_llm)
graph.add_edge("search_mcp", "multi_llm")
graph.add_edge("multi_llm", "validate")
```
