## 1️⃣ CONCEPTO: ¿Qué es AgentCore?

### La Definición Simple

AWS AgentCore es un **servicio managed** diseñado ESPECÍFICAMENTE para agentes de IA.

```
Lambda tradicional: "Sube una función Python"
┌─────────────────────────────┐
│ Corre 15 minutos máximo     │
│ Sin soporte para pausas     │
│ Sin seguridad integrada     │
│ Sin credenciales del usuario│
└─────────────────────────────┘

AWS AgentCore: "Sube tu LangGraph"
┌─────────────────────────────┐
│ Corre horas si lo necesita  │
│ Soporta pausas/reanudación  │
│ Seguridad con Cedar         │
│ Identity Forwarding         │
│ Optimizado para agentes     │
└─────────────────────────────┘
```

## 4️⃣ EJEMPLOS BÁSICOS

### Ejemplo 1: Estructura de un Agente para AgentCore

**Archivo: `ask_sage_agent.py`**
```python
from langgraph.graph import StateGraph, START, END
from typing import TypedDict
import os

# 1. Define el State
class AskSageState(TypedDict):
    user_id: str              # Inyectado por AWS
    user_token: str           # Inyectado por AWS (Identity Forwarding)
    messages: list
    current_action: str
    error: str

# 2. Define los Nodos
def agent_node(state: AskSageState) -> dict:
    """El LLM decide qué hacer"""
    decision = llm.invoke(state["messages"])
    return {"current_action": decision}

def cancel_order_node(state: AskSageState) -> dict:
    """Cancela una orden (con validación)"""
    try:
        # AWS inyectó el token aquí
        user_token = state["user_token"]
        
        # Validar con el token
        if not validate_user(user_token):
            raise PermissionError("Token inválido")
        
        order_id = extract_order_id(state["current_action"])
        result = database.cancel_order(order_id, user_id=state["user_id"])
        
        return {"current_action": f"Orden {order_id} cancelada"}
    except PermissionError as e:
        return {"error": f"Sin permisos: {e}"}
    except Exception as e:
        return {"error": f"Error: {e}"}

# 3. Construye el grafo
graph_builder = StateGraph(AskSageState)
graph_builder.add_node("agent", agent_node)
graph_builder.add_node("cancel", cancel_order_node)
graph_builder.add_edge(START, "agent")
graph_builder.add_conditional_edges("agent", route_decision)
graph_builder.add_edge("cancel", "agent")

# 4. Compilar con checkpointer
from langgraph.checkpoint.sqlite import SqliteSaver

memory = SqliteSaver.from_conn_string("postgresql://...")  # BD real en AWS
graph = graph_builder.compile(checkpointer=memory)

# 5. La función que AWS llamará
def handler(event, context):
    """AWS AgentCore llama a esto"""
    
    # AWS inyecta automáticamente:
    user_id = os.getenv("AWS_USER_ID")
    user_token = os.getenv("AWS_USER_TOKEN")
    
    # El mensaje del usuario
    user_message = event["message"]
    
    # Construir state
    initial_state = {
        "user_id": user_id,
        "user_token": user_token,
        "messages": [{"role": "user", "content": user_message}],
        "current_action": "",
        "error": ""
    }
    
    # Ejecutar con thread_id para tracking
    config = {"configurable": {"thread_id": f"{user_id}_session"}}
    
    try:
        result = graph.invoke(initial_state, config)
        return {"response": result["messages"][-1]}
    except Exception as e:
        return {"error": str(e)}
```

### Ejemplo 3: Cedar Policy (Control Externo)

**Archivo: `policies.cedar`**
```cedar
// Policy 1: Solo administradores cancelen órdenes de otros
permit (
  principal == ?admin,
  action == CancelOrder,
  resource
);

// Policy 2: Usuarios normales cancelen solo sus órdenes
permit (
  principal == ?user,
  action == CancelOrder,
  resource
)
when {
  resource.owner == principal
};

// Policy 3: Nadie cancela órdenes de hace > 30 días
forbid (
  principal,
  action == CancelOrder,
  resource
)
when {
  resource.created_at.days_ago() > 30
};
```

**¿Cuándo se valida?**

```
Tu función Python ejecuta:
  database.cancel_order(order_id)

ANTES de que se ejecute:
  AWS Engine busca policies
  Encuentra: "forbid cancel > 30 días"
  Valida: 60 días? SÍ
  BLOQUEA: "No permitido"
  Tu función NUNCA corre

Tu try/except atrapa:
  except PermissionError:
    return {"error": "No permitido"}
```

## 🎯 Ask Sage Example: Identity Forwarding Farmacéutico

**Escenario Crítico**: Vendedor MX pregunta sobre dosificación. Identity Forwarding debe garantizar que SOLO ve productos de MX.

**SIN Identity Forwarding** ❌:
```
Vendedor MX pregunta: "¿Dosis máxima?"

Backend recibe: {"pregunta": "...", "token_okta": "..."}

// Ooops, olvidamos verificar el token
database.query("""
  SELECT * FROM farmaco_dosis WHERE condicion = 'insuficiencia_renal'
""")

RESULTADO: Ve productos de TODOS los territorios (MX, AR, BR, etc)
💥 Brecha de seguridad: Vendedor MX ve precios de otros territorios
```

**CON Identity Forwarding** ✅:
```python
# backend/ask_sage_handler.py

import os
from aws_agentcore import verify_token, get_user_context

def ask_sage_handler(event: dict, context):
    """
    AWS AgentCore automáticamente inyecta:
    - AWS_USER_TOKEN: Token Okta del vendedor
    - AWS_USER_ID: ID del vendedor (ej: V001)
    - AWS_USER_GROUPS: Territorios (ej: ["MX", "LATAM"])
    """
    
    # 1️⃣ AWS ya validó el token, pero confirmamos identidad
    token = os.getenv("AWS_USER_TOKEN")
    user_id = os.getenv("AWS_USER_ID")
    
    # 2️⃣ Verificar que el token es válido
    try:
        user_info = verify_token(token)  # Okta
        assert user_info["sub"] == user_id  # Asegurar consistencia
    except:
        return {"error": "Token inválido"}
    
    # 3️⃣ Obtener territorios permitidos del token
    user_groups = os.getenv("AWS_USER_GROUPS", "").split(",")  # ["MX", "LATAM"]
    
    # 4️⃣ Construir state con restricción de seguridad
    state = {
        "vendedor_id": user_id,
        "territorios_permitidos": user_groups,  # ✅ CRÍTICO
        "pregunta": event["message"],
        "allowed_products": [],  # Se llenará en siguiente paso
    }
    
    # 5️⃣ LangGraph ejecuta con state restringido
    result = ask_sage_graph.invoke(state)
    
    # 6️⃣ En cada nodo, verificar que el resultado respeta territorios
    for producto in result["respuesta_final"]["productos"]:
        assert producto["territorio"] in state["territorios_permitidos"]
    
    return result

# NODO: Buscar en MCP (respeta identidad)
def nodo_buscar_en_mcp(state: dict) -> dict:
    """
    Este nodo recibe state["territorios_permitidos"]
    Solo busca en esos territorios
    """
    
    territorios = state["territorios_permitidos"]  # ["MX", "LATAM"]
    pregunta = state["pregunta"]
    
    # Query respeta seguridad
    resultados = mcp_client.search(
        pregunta,
        territorio_whitelist=territorios  # ✅ Filtrado
    )
    
    state["search_results"] = resultados
    return state

# VERIFICACIÓN: Cedar Policy (doble validación)
# Archivo: ask_sage_policies.cedar

permit (
  principal == ?vendedor,
  action == SearchDosage,
  resource
)
when {
  // El vendedor solo puede buscar en sus territorios
  principal.territories.contains(resource.territory)
};

forbid (
  principal == ?vendedor,
  action == SearchPrice,
  resource
)
when {
  // Nunca mostrar precios de otros territorios
  !principal.territories.contains(resource.territory)
};
```

**Flujo Completo**:
```
Vendedor MX (token_okta_mx)
        │
        ├─→ AWS recibe y valida token
        │   ✅ Extraigo: user_id=V001, groups=["MX", "LATAM"]
        │
        ├─→ Mi código recibe state con territorios_permitidos=["MX", "LATAM"]
        │
        ├─→ Busco en MCP: "¿Dosis insuf renal?"
        │   Solo en territorios de MX y LATAM
        │   Encontré: Bula MX + Bula LATAM
        │
        ├─→ Cedar Policy valida ANTES de retornar
        │   ✅ Producto MX → permitido
        │   ✅ Producto LATAM → permitido
        │   ❌ Producto BR → BLOQUEADO
        │
        └─→ Respuesta: Solo ve MX + LATAM
            ✅ SEGURO: Vendedor MX no puede ver datos de AR/BR

Intento de ataque (Vendedor MX intenta ver BR):
        │
        ├─→ Manipula request: {"territorios": ["MX", "BR", "LATAM"]}
        │
        ├─→ AWS valida: token_okta_mx solo tiene acceso a ["MX", "LATAM"]
        │   ❌ RECHAZA: "BR no autorizado"
        │
        └─→ Resultado: Error 403 Forbidden
```

**Por qué es crítico para Ask Sage**:
- ✅ **Compliance**: Cada vendedor ve solo sus datos (GDPR, regulaciones farmacéuticas)
- ✅ **Seguridad**: Token validado en AWS, no en tu código
- ✅ **Auditoría**: Cada acceso loguiado con identidad verificada
- ✅ **Multi-región**: Vendedores en MX, AR, BR pueden usar el mismo backend

### Ejercicio 2: ¿Qué Falta?

**Código:**
```python
def update_inventory(drug_id, quantity):
    # Cancela la orden del medicamento
    # ❌ IDENTIFICA 3 PROBLEMAS DE SEGURIDAD
    
    db.execute(f"UPDATE drugs SET stock = {quantity} WHERE id = {drug_id}")
    return "Stock actualizado"

def handler(event, context):
    drug_id = event["drug_id"]
    quantity = event["quantity"]
    update_inventory(drug_id, quantity)
```

**Respuesta:**
```
Problema 1: No validar user_token
  → "¿Quién está haciendo esto?"

Problema 2: Sin try/except
  → "¿Qué si falla por permisos?"

Problema 3: No hay Cedar policy
  → "¿Quién puede actualizar stock?"

Solución:
```

```python
def update_inventory(drug_id, quantity, state: AskSageState) -> dict:
    try:
        # 1. Validar usuario
        user_token = state["user_token"]
        user_info = validate_token(user_token)
        
        # 2. Validar rol (Cedar va a validar también)
        if user_info["role"] != "pharmacist":
            raise PermissionError("Solo farmacéuticos")
        
        # 3. Query segura (sin SQL injection)
        db.update_drug_stock(drug_id, quantity)
        
        return {"status": "Stock actualizado"}
    
    except PermissionError as e:
        return {"error": f"Permiso denegado: {e}"}
    except Exception as e:
        return {"error": f"Error: {e}"}
```

## 🎯 Conceptos Clave

| Término | Significado | En AgentCore |
|---------|-----------|-------------|
| **Identity Forwarding** | AWS pasa credenciales | Tu código recibe `user_token` |
| **Cedar Policy** | Política de seguridad externa | AWS valida ANTES de ejecutar |
| **Checkpoint** | Estado guardado en BD | AgentCore reanuda desde aquí |
| **User Token** | Credencial del usuario | Pasas a BD/APIs |
| **Permission Error** | Acceso denegado | Maneja con try/except |
