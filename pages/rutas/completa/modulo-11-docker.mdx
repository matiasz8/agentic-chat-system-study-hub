## Entiende

Docker Compose: "Toda la app en un comando."

```yaml
services:
  frontend:
    image: ask-sage-frontend
    ports:
      - "3000:3000"
  
  backend:
    image: ask-sage-backend
    ports:
      - "8000:8000"
```

Ventajas:
- Reproducible
- Production-like
- Fácil compartir

## Ejecuta

```bash
# Build images
docker build -t ask-sage-frontend ./frontend
docker build -t ask-sage-backend ./backend

# Run
docker compose up

# Verifica
curl http://localhost:3000      # Frontend
curl http://localhost:8000/health  # Backend
```
