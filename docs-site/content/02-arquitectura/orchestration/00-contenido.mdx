                  └──────────────┬───────────────┘
                                 │
                    ┌────────────▼────────────┐
                    │  ARISTA: Condicional   │
                    │  (if resultado == X)   │
                    │     → Node A           │
                    │  (else)                │
                    │     → Node B           │
                    └────────────┬────────────┘
                                 │
                    ┌────────────▼──────────┐

                    │  (persistencia en DB) │

## 💡 Ejemplo Rápido: El Poder de LangGraph

### ❌ Sin LangGraph (Código Tradicional)

```python
# Anidación infinita, difícil de debuggear
def process_user_query(user_input):
    if user_input.contains("stock"):
        stock = query_database()
        if stock < 10:
            alert = generate_alert()
            if user.is_premium:
                send_email(alert)
            else:
                send_sms(alert)
        else:
            response = "Stock OK"
    elif user_input.contains("order"):
        # ... más lógica
    # ... 50 líneas de if/else
```

### ✅ Con LangGraph (Grafo)

```python
# Claro, escalable, debuggeable
from langgraph.graph import StateGraph, START, END

class AgentState(TypedDict):
    user_input: str
    stock: int
    response: str

def check_stock(state):
    state["stock"] = query_database(state["user_input"])
    return state

def route_by_stock(state):
    if state["stock"] < 10:
        return "send_alert"
    else:
        return "send_ok"

graph = StateGraph(AgentState)
graph.add_node("check_stock", check_stock)
graph.add_edge(START, "check_stock")
graph.add_conditional_edges("check_stock", route_by_stock, {
    "send_alert": END,
    "send_ok": END
})

compiled = graph.compile()
result = compiled.invoke({"user_input": "stock", "stock": 0, "response": ""})
```

**Diferencia**: El grafo es visual, testeable, y escalable. 🚀
