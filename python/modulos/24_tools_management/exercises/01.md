# Ejercicio 1: ToolRegistry básico

## 🎯 Objetivo

Registrar callables con metadatos y poder descubrirlos por nombre.

## 📋 Descripción

Construye un `ToolRegistry` que soporte:

- registrar funciones con nombre, descripción y esquema estilo JSON Schema;
- listar las tools disponibles;
- buscarlas por nombre;
- invocarlas con un payload simple.

## 💡 Pistas

- Un decorador `@register(...)` hace la API más cómoda.
- Guarda cada definición en una dataclass.
- Empieza sin validación estricta; solo enfócate en catálogo e invocación.

## ✅ Criterios de Éxito

- Hay al menos dos tools registradas.
- El programa imprime el catálogo.
- Puedes invocar una tool por nombre.
- Todo corre con stdlib.

## 🚀 Bonus

Agrega una búsqueda por categoría o tag.
