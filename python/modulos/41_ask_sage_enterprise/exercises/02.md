# Ejercicio 2: RBAC sobre Ask Sage

## 🎯 Objetivo
Agregar control de acceso por roles al momento de recuperar documentos.

## 📋 Descripción
Define usuarios con roles `admin`, `editor` y `viewer`. Cada documento debe requerir un permiso específico. La búsqueda debe filtrar primero por tenant y luego por permiso autorizado para el usuario actual.

## 💡 Pistas
- Usa un diccionario `ROLE_PERMISSIONS`.
- Implementa una función `can_access(user, document)`.
- Evalúa permisos antes de rankear relevancia.
- Prueba con un documento público y otro restringido.

## ✅ Criterios de Éxito
- Un usuario viewer no ve documentos restringidos.
- Un admin sí puede acceder a documentos restringidos.
- La lógica de autorización está separada de la de búsqueda.
- La salida muestra decisiones permitidas y denegadas.

## 🚀 Bonus
Registra intentos denegados para alimentar una futura auditoría de seguridad.
