# El State (Estado Centralizado) en LangGraph

> State: Memoria del Grafo
TypedDict + contexto compartido entre nodos.

El **State** es la memoria compartida de tu agente. Todo viaja por aquí: mensajes, contexto, resultados, errores.

Piénsalo así: Si tu agente es un cerebro, el State es la sangre. 🧠💉

---

## 🔄 ¿Qué es el State?

```
┌──────────────────────────────────────────┐
│        STATE (Diccionario Python)        │
├──────────────────────────────────────────┤
│ {                                        │
│   "messages": ["Hola", "Mundo"],         │
│   "current_step": "processing",          │
│   "user_id": "user_123",                 │
│   "results": [],                         │
│   "errors": []                           │
│ }                                        │
└──────────┬────────────────────┬──────────┘
           │                    │
      ┌────▼───┐           ┌────▼──┐
      │ Node 1 │           │ Node 2│
      │ (LEER) │           │ (LEER)│
      └────┬───┘           └────┬──┘
           │ (actualiza)      │ (actualiza)
           └────────┬─────────┘
                    │
           ┌────────▼─────────┐
           │ State Actualizado│
           │ (persistencia)   │
           └──────────────────┘
```

### 3 Principios

✅ **Centralizado**: Un único punto de verdad  
✅ **Inmutable**: Cada cambio crea nuevo estado  
✅ **Tipado**: Defines explícitamente qué contiene

---

## 💻 Nivel 1: State Básico

El form más simple es un **TypedDict**:

**Cuándo usar**: Prototipos rápidos, demos, desarrollo local

---

## 💻 Nivel 2: State Intermedio (Con Reducers)

Cuando necesitas **control granular** sobre cómo se actualiza cada campo:

**Ventaja**: Control preciso de cómo se actualizan datos  
**Cuándo usar**: Agentes con múltiples nodos, conversaciones, históricos

---

## 💻 Nivel 3: State Avanzado (Custom Reducers)

Para casos complejos, define **reducers personalizados**:

**Cuándo usar**: Producción, agentes con requisitos de seguridad/compliance

## 🎯 Ask Sage Example: State Farmacéutico

**Escenario**: Vendedor MX pregunta sobre dosis. El State viaja por todo el grafo guardando información.

```python
from typing import TypedDict, Annotated, Literal
from operator import add

class AskSageState(TypedDict):
    # INPUT
    vendedor_id: str                    # "V001"
    territorio: str                     # "MX"
    pregunta: str                       # "¿Dosis insuf. renal?"
    
    # CONTEXTO DE SEGURIDAD (Identity Forward)
    allowed_products: list              # ["P001", "P002", "P003"]
    allowed_territories: list           # ["MX", "LATAM"]
    user_roles: list                    # ["Sales", "Senior"]
    
    # HISTÓRICO DE CONVERSACIÓN
    messages: Annotated[list, add]      # Acumula todo lo que sucede
    
    # BÚSQUEDA EN DATA LAYER
    search_results: dict                # PDFs encontrados, DB queries, videos
    confidence_score: float             # 0-1 (qué tan seguro está)
    
    # ESTADO DE ORQUESTACIÓN
    current_step: Literal[
        "authorize",        # Verificar identidad
        "search",           # Buscar en MCP
        "generate",         # Generar respuesta
        "validate",         # Validar confianza
        "approve",          # Esperar aprobación humana?
        "respond"           # Enviar respuesta
    ]
    
    # RESULTADO FINAL
    respuesta_final: str                # La respuesta para el vendedor
    requiere_aprobacion_humana: bool    # Si confidence < 0.8
    audit_trail: Annotated[list, add]   # Log de cada paso
```

**Cómo viaja el State**:

```
[INICIAL]
{
  vendedor_id: "V001",
  territorio: "MX",
  pregunta: "¿Dosis insuf. renal?",
  allowed_products: [],
  messages: [],
  current_step: "authorize"
}
      │
      ├─→ [NODO 1: Authorize]
      │   • Lee: vendedor_id, territorio
      │   • Verifica token Okta ✅
      │   • Actualiza: allowed_products, messages, audit_trail
      │
      ├─→ [NODO 2: Search]
      │   • Lee: allowed_products, pregunta
      │   • Busca en PDFs, DB, Videos usando MCP
      │   • Actualiza: search_results, confidence_score, messages
      │
      ├─→ [NODO 3: Generate]
      │   • Lee: search_results, allowed_products
      │   • Genera respuesta (puede incluir tablas React)
      │   • Actualiza: respuesta_final, messages
      │
      ├─→ [NODO 4: Validate]
      │   • Lee: confidence_score
      │   • Si >= 0.8 → siguiente step
      │   • Si < 0.8 → requiere_aprobacion_humana = True
      │   • Actualiza: current_step
      │
      └─→ [FINAL: Respond]
          • Envía respuesta al frontend con streaming
          • Loga en audit_trail

[FINAL]
{
  # ...todos los anteriores...
  respuesta_final: "Dosis máxima: 100mg/día...",
  requiere_aprobacion_humana: False,
  current_step: "respond",
  messages: [
    "[authorize]: Vendedor V001 verificado en territorio MX",
    "[search]: Encontrada bula en PDF pág 12",
    "[generate]: Respuesta generada con confianza 0.95",
    "[validate]: Confianza suficiente, proceder"
  ],
  audit_trail: [
    {"step": "authorize", "duration": "0.05s", "status": "ok"},
    {"step": "search", "duration": "0.80s", "status": "ok", "sources": 3},
    {"step": "generate", "duration": "1.20s", "status": "ok"},
    {"step": "validate", "duration": "0.02s", "status": "ok"}
  ]
}
```

**Por qué es importante**:
- ✅ **Auditoría**: Cada vendedor, cada pregunta, cada decisión está loguiada
- ✅ **Debugging**: Si algo falla, ves exactamente dónde
- ✅ **Seguridad**: `allowed_products` viaja con la pregunta, evita cheats
- ✅ **Persistencia**: El State se puede guardar en DB para pause/resume
