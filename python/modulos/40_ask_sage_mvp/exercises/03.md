# Ejercicio 3: MVP Completo con Chat y Sesiones

## 🎯 Objetivo
Integrar ingestión, recuperación y gestión de sesiones en una simulación completa de Ask Sage MVP.

## 📋 Descripción
Diseña un sistema con `DocumentManager`, `SessionManager` y `MockLLM`. El flujo debe aceptar una pregunta, recuperar chunks, generar una respuesta y guardar el intercambio en el historial de la sesión.

## 💡 Pistas
- Usa clases pequeñas y enfocadas.
- Crea una sesión con un identificador único.
- Separa autenticación, recuperación y generación.
- Imprime el historial final para demostrar memoria conversacional.

## ✅ Criterios de Éxito
- Existe una sesión por usuario con historial persistido en memoria.
- La respuesta usa contexto recuperado.
- El flujo es ejecutable desde CLI sin dependencias externas.
- El código demuestra la arquitectura MVP completa.

## 🚀 Bonus
Simula streaming imprimiendo la respuesta palabra por palabra con una pequeña pausa.
