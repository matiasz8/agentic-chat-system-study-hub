# Ejercicio 1: Lambda + SQS + DLQ

## 🎯 Objetivo
Escribir un handler Lambda que procese mensajes de SQS, maneje errores correctamente y derive mensajes fallidos a una cola lógica de DLQ.

## 📋 Descripción
Recibirás un evento con `Records`. Cada mensaje contiene información sobre una tarea del agente. Si el payload es inválido o la tarea falla, debes registrar el error y enviar el mensaje a una estructura `dead_letter_queue`.

## 💡 Pistas
- Recorre `event.get("Records", [])`.
- Usa `json.loads` para parsear `body`.
- Captura excepciones por mensaje para no abortar todo el batch.
- Devuelve un resumen con procesados, fallidos y elementos en DLQ.

## ✅ Criterios de Éxito
- El handler procesa mensajes válidos.
- Los errores no rompen el lote completo.
- Los fallos quedan visibles en una DLQ lógica.
- El programa es ejecutable y muestra un resumen final.

## 🚀 Bonus
Agrega un contador de reintentos por mensaje antes de enviarlo definitivamente a la DLQ.
