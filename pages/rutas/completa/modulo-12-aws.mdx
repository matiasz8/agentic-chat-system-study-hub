## Estructura AWS

```
ECR (Registry)
  ↓
ECS Cluster
  ├─ Frontend Task
  └─ Backend Task
  
ALB (Load Balancer) → Frontend
Target Group → Backend
```

## Ejecuta

**Paso 1: ECR Setup**
```bash
aws ecr create-repository --repository-name ask-sage-frontend
aws ecr create-repository --repository-name ask-sage-backend
```

**Paso 2: Build & Push**
```bash
docker build -t ask-sage-frontend ./frontend
docker tag ask-sage-frontend:latest <account>.dkr.ecr.us-east-1.amazonaws.com/ask-sage-frontend:latest
aws ecr get-login-password | docker login --username AWS --password-stdin <account>.dkr.ecr.us-east-1.amazonaws.com
docker push <account>.dkr.ecr.us-east-1.amazonaws.com/ask-sage-frontend:latest
```

**Paso 3: ECS Deploy**
```bash
aws ecs update-service --cluster ask-sage --service frontend --force-new-deployment
```

**Paso 4: Verify**
```bash
curl https://ask-sage.yourdomain.com/health
```
