## 🛠️ RUTA POC (14-21 días - Desarrollo)

> Para: Quiero CONSTRUIR Ask Sage funcional (necesita ask-sage-poc repo)

**Meta**: POC funcionando en 2-3 semanas

```
SEMANA 1: SETUP + FRONTEND
├─ DÍA 1-2: Next.js + Vercel AI SDK
│  ├─ Clona ask-sage-poc repo
│  ├─ npm install
│  └─ npm run dev → http://localhost:3000
├─ DÍA 3: Implementa AskSageChat.tsx
│  ├─ useChat hook
│  ├─ Streaming UI
│  └─ Test con LLM mock
└─ DÍA 4-5: Deploy a Vercel
   └─ git push → automático

SEMANA 2: BACKEND + ORCHESTRATION
├─ DÍA 6: Setup FastAPI
│  ├─ python -m venv venv
│  └─ pip install -r requirements.txt
├─ DÍA 7-10: LangGraph + 3 nodos
│  ├─ nodo_verificar_identidad (mock Okta)
│  ├─ nodo_buscar_en_mcp (búsqueda)
│  └─ nodo_responder (LLM)
└─ DÍA 11: Tests
   └─ pytest python/

SEMANA 3: DEPLOYMENT
├─ DÍA 12-14: AWS
│  ├─ CloudFormation templates
│  ├─ Lambda deployment
│  └─ Identity Forwarding real
└─ DÍA 15-21: Polish + Docs
   └─ Production-ready
```

**Resultado**: POC ejecutable en producción ✅

⚠️ **IMPORTANTE**: Esta ruta requiere:
- [ ] ask-sage-poc repo (separado, con código completo)
- [ ] Experiencia escribiendo código
- [ ] AWS account configurada
- [ ] 3 semanas dedicadas

## 🎯 ¿Cuál Elegir?

### Elige ESTUDIO RÁPIDO si:
- ✅ Eres gestor/jefe y quieres entender arquitectura
- ✅ Tienes 3-5 días disponibles
- ✅ Necesitas decisiones informadas ANTES de dev
- ✅ No quieres escribir código (aún)

**→ [Empezar Estudio Rápido](#estudio-rápido-3-5-días---teoría--ejemplos)**

### Elige ESTUDIO COMPLETO si:
- ✅ Eres architect/senior dev
- ✅ Quieres dominar TODA la arquitectura
- ✅ Tienes 3 semanas
- ✅ Necesitas hacer technical interviews
- ✅ Vas a revisar código POC luego

**→ [Empezar Estudio Completo](#ruta-completa-21-días---expert)**

### Elige RUTA POC si:
- ✅ Eres dev y vas a ESCRIBIR el código
- ✅ Tienes 2-3 semanas dedicadas
- ✅ Ask-sage-poc repo ya existe
- ✅ Necesitas POC en producción

**→ [Empezar POC Development](#ruta-poc-14-21-días---desarrollo)**

### ⭐ Recomendación Oficial (Para tu Jefe):
**ESTUDIO RÁPIDO** (3-5 días) = Entiende TODO antes de comprometerse con dev team

## 🔗 Módulo ↔ Código: Paralelismo

Cada módulo de la web tiene código correspondiente en **ask-sage-starter**.

### Ejemplo: State (Módulo 11)

```
PÁGINA WEB:
/orchestration/11-state.mdx
├─ Concepto: AskSageState TypedDict
├─ Ejemplo: State centralizado
└─ Ejercicio: Define tu State

↓ CORRESPONDE A ↓

CÓDIGO (ask-sage-starter):
backend/ask_sage_graph.py
├─ Línea 5-20: class AskSageState(TypedDict)
├─ Línea 25-35: Uso en nodos
└─ Línea 60-65: Actualización

INSTRUCCIONES:
1. Lee /orchestration/11-state (45 min)
2. Abre backend/ask_sage_graph.py
3. Reconoce AskSageState
4. Modifica un campo (ej: agrega "temperatura")
5. VES CAMBIOS EN http://localhost:3000
```
