# Caso de Uso: Ask Sage

## Escenario

Una clínica requiere un asistente que pueda:
1. Responder preguntas sobre medicamentos
2. Detectar interacciones peligrosas
3. Mantener auditoría completa para reguladores
4. Controlar acceso por rol (médico, farmacéutico, administrador)

## Flujo básico

```
Usuario → Pregunta → Agente → Búsqueda de datos → Validación → Respuesta
                              ↓
                        Registro de auditoría
```
