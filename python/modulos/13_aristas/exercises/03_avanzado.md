# Ejercicio 03 — Routing dinámico con fallback

Implementa un balanceador que seleccione workers por carga y, si uno falla, redirija el trabajo a un worker de respaldo.

## Requisitos
- Usa una clase `Worker`.
- Ejecuta al menos dos rutas en paralelo.
- Registra en `route_log` cuándo se activa el fallback.
