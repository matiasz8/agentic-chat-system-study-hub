# 03. Implementar Grafo (2 horas)

> Crear tu primer grafo con 3 nodos.

## 🎯 Objetivo

Crear un grafo con estos nodos:
1. `verify_identity` - Valida usuario
2. `search_mcp` - Simula búsqueda
3. `format_response` - Formatea respuesta

---

## 📝 Código

```python
# backend/graph.py
from langgraph.graph import StateGraph, END
from pydantic import BaseModel
from typing import Optional

class AgentState(BaseModel):
    user_id: str
    query: str
    search_result: Optional[str] = None
    response: str = ""

# Nodo 1: Verificar identidad
def verify_identity(state: AgentState):
    if state.user_id:
        return {"response": f"✓ Usuario {state.user_id} verificado"}
    return {"response": "✗ Usuario no válido"}

# Nodo 2: Buscar información
def search_mcp(state: AgentState):
    # Simular búsqueda
    results = {
        "medicamento": "Resultado de búsqueda simulada",
        "stock": "500 unidades"
    }
    return {"search_result": str(results)}

# Nodo 3: Formatear respuesta
def format_response(state: AgentState):
    if state.search_result:
        return {
            "response": f"Búsqueda: {state.search_result}"
        }
    return {"response": "Sin resultados"}

# Arista condicional
def route(state: AgentState):
    if "usuario no válido" in state.response:
        return END
    return "search_mcp"

# Crear grafo
graph = StateGraph(AgentState)

graph.add_node("verify", verify_identity)
graph.add_node("search_mcp", search_mcp)
graph.add_node("format", format_response)

graph.set_entry_point("verify")
graph.add_conditional_edges("verify", route)
graph.add_edge("search_mcp", "format")
graph.set_finish_point("format")

# Compilar
agent = graph.compile()
```
