# 🚀 Bienvenido al Agentic Chat System Study Hub

> Tu guía completa para entender y construir sistemas agentic basados en Ask Sage

Elegiste el lugar correcto. Este hub tiene **todo lo que necesitas** para ir de "¿qué es un agente?" a "tengo un sistema en producción en AWS AgentCore".

## 🎯 ¿Qué Quieres Hacer?

Elige tu ruta. Cada una está optimizada para un objetivo específico.

"Quiero *entender* la arquitectura"

- 📚 Lectura profunda
- 🧠 Conceptos teóricos
- 📊 Diagramas y arquitectura
- ✅ Ideal para: Aprender, tomar decisiones arquitectónicas

**Tiempo**: 8 horas (Rápida) o 20 horas (Completa)  
**Salida**: Comprensión profunda de sistemas agentic  
**→ [Ir a Ruta Estudio](/rutas/estudio)**

### 🟡 **Ruta POC** (16 horas)
"Quiero *hacer algo ejecutable*"

- 💻 Código paso-a-paso
- 🎯 32+ ejercicios prácticos
- 🐳 Docker local incluido
- 🧪 Testing integrado
- ✅ Ideal para: Prototipar, aprender haciendo

**Tiempo**: 16 horas (todo incluido)  
**Salida**: POC funcionando localmente  
**→ [Ir a Ruta POC](/rutas/poc)**

---

### 🔴 **Ruta Producción** (2-3 semanas)
"Quiero *deploy real en AWS*"

- ☁️ AWS AgentCore
- 🔐 Identity Forwarding + Governance
- 📋 Checklist pre-go-live
- 🆘 Troubleshooting completo
- ✅ Ideal para: Llevar a producción, Ask Sage real

**Tiempo**: 2-3 semanas (con Ruta POC como base)  
**Salida**: Sistema en producción AWS + monitoreo  
**→ [Ir a Ruta Producción](/rutas/produccion)**

## 🤔 Preguntas Frecuentes

**P: ¿Necesito experiencia previa?**  
R: Básicos de Python + JavaScript. Explicamos el resto.

**P: ¿Cuánto tarda el POC?**  
R: 16 horas si sigues paso-a-paso. Menos si ya conoces LangGraph.

**P: ¿Es para Ask Sage solamente?**  
R: No. Es para cualquier sistema agentic. Ask Sage es un caso de uso.

**P: ¿Hay código ejecutable?**  
R: Sí. Docker Compose incluido en Ruta POC.

**P: ¿Puedo saltar la Ruta Estudio?**  
R: No recomendado. La teoría es importante para decisiones en POC.
