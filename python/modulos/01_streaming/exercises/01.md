# Ejercicio 1: Generador de Respuesta Incremental

## 🎯 Objetivo
Implementar un generador que emita una respuesta falsa de LLM token por token y la imprima apenas esté disponible.

## 📋 Descripción
Crea una función `stream_fake_response(texto: str)` que recorra una respuesta palabra por palabra. Debe usar `yield` para entregar cada token y un pequeño `sleep` para simular latencia de generación. Luego, en `main()`, imprime cada token inmediatamente usando `flush=True` o `sys.stdout.flush()`.

La meta es notar la diferencia entre construir toda la respuesta al final y mostrar progreso desde el primer token.

## 💡 Pistas
- `texto.split()` te da una secuencia fácil de tokens.
- `time.sleep(0.1)` alcanza para simular streaming.
- Usa una lista para reconstruir la respuesta completa al final.
- Si no haces flush, la salida puede quedar bufferizada.

## ✅ Criterios de Éxito
- Existe un generador con `yield`.
- Los tokens aparecen uno por uno en consola.
- El script tiene `main()` y guard clause.
- Al final se imprime la respuesta completa reconstruida.

## 🚀 Bonus
Permite configurar el delay por parámetro y agrega un contador de token (`Token 1`, `Token 2`, etc.).
