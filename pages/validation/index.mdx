# Validación: Testing & QA

## 🎯 Objetivo

Aprende a validar que tus prompts, workflows y sistemas funcionan correctamente.

## 📚 Módulos

### Nivel Principiante
- **00. Testing Básico** - Assertions y casos de prueba simples
- **01. Testing de Prompts** - Validar salidas de LLM

### Nivel Intermedio
- **02. Validación de Workflows** - Testing de LangGraph
- **03. E2E Testing** - Pruebas end-to-end

### Nivel Avanzado
- **04. CI/CD Validation** - Automatizar validaciones

## 🚀 Quick Start

```bash
# Ejecutar tests básicos
pytest python/modulos/50_testing_basico/

# Validar workflows
python examples/workflow_validation.py

# CI/CD checks
./scripts/validate-all.sh
```
