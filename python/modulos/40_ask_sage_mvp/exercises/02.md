# Ejercicio 2: Pipeline RAG con Respuesta Simulada

## 🎯 Objetivo
Implementar una tubería RAG simple que recupere chunks relevantes, construya un prompt y genere una respuesta simulada basada en contexto.

## 📋 Descripción
Parte de una lista de chunks ya indexados. Dada una pregunta, encuentra los chunks más relevantes con keywords, arma un prompt legible y genera una respuesta que resuma el contexto hallado.

## 💡 Pistas
- Normaliza la pregunta a minúsculas.
- Calcula un score por coincidencias de tokens.
- Usa solo los 2 o 3 chunks mejor rankeados.
- Si no hay coincidencias, devuelve una respuesta honesta.

## ✅ Criterios de Éxito
- La pregunta devuelve una lista ordenada de chunks relevantes.
- El prompt muestra instrucciones, pregunta y contexto.
- La respuesta resume el contexto recuperado.
- La ejecución imprime cada fase del flujo.

## 🚀 Bonus
Añade una etapa de “confidence score” basada en la cantidad de tokens recuperados.
