# Ejercicio 1: SimilaritySearch con cosine similarity

## 🎯 Objetivo
Implementar una clase `SimilaritySearch` que calcule similitud coseno sobre vectores generados a partir de texto con un enfoque tipo TF-IDF simplificado.

## 📋 Descripción
Crea una clase que reciba una lista de documentos, construya un vocabulario, genere embeddings numéricos y permita ejecutar `search(query, top_k=3)`. Tu implementación debe devolver los documentos ordenados por mayor similitud.

No necesitas librerías de ML. El foco está en entender tokenización, pesos y ranking.

## 💡 Pistas
- `collections.Counter` es útil para TF.
- Calcula IDF con logaritmos del módulo `math`.
- Si un vector queda vacío, devuelve score `0.0`.

## ✅ Criterios de Éxito
- La clase produce resultados consistentes para distintas consultas.
- `search()` retorna score y documento.
- La similitud coseno está implementada manualmente.

## 🚀 Bonus
Soporta stopwords simples como `de`, `la`, `y`, `para` para mejorar el ranking.
