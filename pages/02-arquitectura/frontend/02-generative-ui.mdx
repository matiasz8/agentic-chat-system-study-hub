## 1️⃣ CONCEPTO: ¿Qué es Generative UI?

### La Idea Revolucionaria

**Streaming de Texto (Módulo 9):**
```
Backend:     El stock es...
             El stock es 1500...
             El stock es 1500 unidades...

Frontend:    Muestra TEXTO progresivamente
```

**Generative UI (Este Módulo):**
```
Backend:     [ENVÍA COMPONENTE REACT]
             <StockChart data={...} />
             [ENVÍA OTRO COMPONENTE]
             <OrderButton />

Frontend:    Renderiza COMPONENTES progresivamente
             No texto: interfaz dinámica
```

### Visual

```
Sin Generative UI:
┌─────────────────────────────┐
│ Chat                        │
├─────────────────────────────┤
│ Bot: El stock es 1500       │
│ unidades. Hay bajo stock    │
│ en las sucursales...        │
└─────────────────────────────┘

Con Generative UI:
┌─────────────────────────────┐
│ Chat                        │
├─────────────────────────────┤
│ Bot: Comparación de stock   │
│                             │
│ [Gráfico interactivo]       │
│  Sede A: 1500 │███████████  │
│  Sede B: 450  │███          │
│  Sede C: 200  │██           │
│                             │
│ [Botón: "Requisición"]      │
└─────────────────────────────┘
```

## 4️⃣ EJEMPLOS BÁSICOS

### Ejemplo 1: Backend - Usar streamUI

**Archivo: `app/api/chat/route.ts`**

```typescript
import { streamUI } from 'ai/react-server';
import { z } from 'zod';

export async function POST(req: Request) {
  const { message } = await req.json();
  
  const result = await streamUI({
    model: bedrock,
    prompt: message,
    text: {
      // Si el LLM decide SOLO responder con texto
      type: 'text',
    },
    tools: {
      // Las herramientas que el LLM puede invocar
      
      showStockComparison: {
        description: 'Muestra un gráfico comparativo de stock',
        parameters: z.object({
          drugA: z.string().describe('Primer medicamento'),
          drugB: z.string().describe('Segundo medicamento'),
        }),
        generate: async ({ drugA, drugB }) => {
          // 1. Backend obtiene los datos
          const dataA = await getStockData(drugA);
          const dataB = await getStockData(drugB);
          
          // 2. Retorna un componente React
          return (
            <StockComparisonChart 
              medicineA={{ name: drugA, data: dataA }}
              medicineB={{ name: drugB, data: dataB }}
            />
          );
        },
      },
      
      showOrderForm: {
        description: 'Muestra formulario para hacer una orden',
        parameters: z.object({
          medicineId: z.string(),
          quantity: z.number(),
        }),
        generate: async ({ medicineId, quantity }) => {
          const price = await getPrice(medicineId);
          
          return (
            <OrderForm 
              medicineId={medicineId}
              recommendedQty={quantity}
              pricePerUnit={price}
            />
          );
        },
      },
    },
  });
  
  return result.toDataStream();
}
```

### Ejemplo 2: El Componente React (React Server Component)

**Archivo: `components/StockComparisonChart.tsx`**

```typescript
'use client'; // Client component (necesario para interactividad)

import { BarChart, Bar, XAxis, YAxis, Tooltip } from 'recharts';

interface StockData {
  location: string;
  quantity: number;
}

interface Medicine {
  name: string;
  data: StockData[];
}

export function StockComparisonChart({
  medicineA,
  medicineB,
}: {
  medicineA: Medicine;
  medicineB: Medicine;
}) {
  // Preparar datos para el gráfico
  const chartData = medicineA.data.map((locA) => ({
    location: locA.location,
    [medicineA.name]: locA.quantity,
    [medicineB.name]: medicineB.data.find(
      (locB) => locB.location === locA.location
    )?.quantity || 0,
  }));
  
  return (
    <div className="chart-container">
      <h3>Comparación: {medicineA.name} vs {medicineB.name}</h3>
      
      <BarChart width={500} height={300} data={chartData}>
        <XAxis dataKey="location" />
        <YAxis />
        <Tooltip />
        <Bar dataKey={medicineA.name} fill="#8884d8" />
        <Bar dataKey={medicineB.name} fill="#82ca9d" />
      </BarChart>
      
      <div className="summary">
        <p>
          <strong>{medicineA.name}</strong> tiene {
            medicineA.data.reduce((sum, d) => sum + d.quantity, 0)
          } unidades en total
        </p>
        <p>
          <strong>{medicineB.name}</strong> tiene {
            medicineB.data.reduce((sum, d) => sum + d.quantity, 0)
          } unidades en total
        </p>
      </div>
    </div>
  );
}
```

### Ejemplo 3: Frontend - Usar streamUI

**Archivo: `components/ChatComponent.tsx`**

```typescript
'use client';

import { useChat } from 'ai/react';
import { ReactNode } from 'react';

interface Message {
  id: string;
  role: 'user' | 'assistant';
  content: string | ReactNode; // Puede ser texto O componente
}

export default function ChatComponent() {
  const { messages, input, handleInputChange, handleSubmit } = useChat({
    api: '/api/chat',
  });
  
  return (
    <div className="chat">
      <div className="messages">
        {(messages as Message[]).map((message) => (
          <div key={message.id} className={`message ${message.role}`}>
            {/* ✨ Puede ser texto o componente React */}
            {message.content}
          </div>
        ))}
      </div>
      
      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Pregunta algo..."
        />
        <button type="submit">Enviar</button>
      </form>
    </div>
  );
}
```

**¿Cómo funciona la magia?**

1. Usuario escribe: "Compara A vs B"
2. Frontend envía POST a `/api/chat`
3. Backend con streamUI:
   - LLM lee: "¿Debo mostrar gráfico?"
   - LLM decide: "Sí, uso showStockComparison"
   - Backend: Llama a `generate()`
   - `generate()` devuelve `<StockComparisonChart />`
   - Vercel serializa el componente
   - Envía al cliente
4. Cliente renderiza el componente
   - No es texto, es un componente REAL
   - Con datos, interactividad, etc

### Ejemplo 4: Componente Más Complejo (Con Botones)

**Archivo: `components/OrderForm.tsx`**

```typescript
'use client';

import { useState } from 'react';
import { useFormStatus } from 'react-dom';

interface OrderFormProps {
  medicineId: string;
  recommendedQty: number;
  pricePerUnit: number;
}

export function OrderForm({
  medicineId,
  recommendedQty,
  pricePerUnit,
}: OrderFormProps) {
  const [quantity, setQuantity] = useState(recommendedQty);
  const { pending } = useFormStatus();
  
  const total = quantity * pricePerUnit;
  
  async function handleOrder() {
    const response = await fetch('/api/orders', {
      method: 'POST',
      body: JSON.stringify({
        medicineId,
        quantity,
      }),
    });
    
    if (response.ok) {
      alert('Orden creada!');
    }
  }
  
  return (
    <div className="order-form">
      <h4>Crear Orden</h4>
      
      <div className="form-group">
        <label>Cantidad</label>
        <input
          type="number"
          value={quantity}
          onChange={(e) => setQuantity(parseInt(e.target.value))}
          min="1"
        />
      </div>
      
      <div className="summary">
        <p>Precio unitario: ${pricePerUnit}</p>
        <p><strong>Total: ${total}</strong></p>
      </div>
      
      <button 
        onClick={handleOrder}
        disabled={pending}
      >
        {pending ? 'Procesando...' : 'Confirmar Orden'}
      </button>
    </div>
  );
}
```

**¿Qué hace diferente?**
- No es solo lectura
- Tiene estado (`useState`)
- Tiene acciones (`handleOrder`)
- Es un componente VIVO generado por IA

## 🎯 Conceptos Clave

| Término | Significado | En Generative UI |
|---------|-----------|--------------|
| **streamUI** | Stream de componentes | Backend envía React |
| **RSC** | React Server Component | Componente generado en servidor |
| **generate()** | Función que retorna JSX | Dónde creas el componente |
| **tool_use** | LLM decide usar herramienta | LLM: "Necesito gráfico" |
| **Serialization** | Componente → JSON → Cliente | Vercel lo maneja |

## 💡 Tips Finales

1. **Generative UI es el futuro**
   - No siempre es más complejo que texto
   - Pero la UX es MUCHO mejor

2. **Los componentes deben ser simples**
   - No intentes gráficos 3D generados
   - Recharts, Plotly, simple HTML

3. **Testing es crítico**
   - ¿Qué si el LLM genera gráfico mal?
   - Necesitas fallbacks (texto si falla)

```typescript
// Ejemplo de fallback
try {
  return <StockChart data={data} />;
} catch (e) {
  return <div>Error en gráfico: {e.message}</div>;
}
```
