## ¿Por Qué?

Ahora: Mock hardcoded `territorio = "MX"`

Realidad: Okta controla todo:
- ¿Quién eres?
- ¿Qué territorios puedes acceder?
- ¿Qué grupos perteneces?

Sin Okta real = no es producción.

## Arquitectura

```
Frontend → envía JWT token
  ↓
Backend recibe token
  ↓
Valida con Okta
  ↓
Extrae claims: territorio, grupos, permisos
  ↓
Filtra datos según territorio
```

En `backend/ask_sage_graph.py`:

```python
from okta.client import Client as OktaClient
from jose import jwt, JWTError

async def nodo_verificar_identidad(state):
    token = state.get("auth_token")
    
    if not token:
        return {"error": "No token provided"}
    
    try:
        # Verificar token con Okta
        okta_client = OktaClient({
            "client_id": os.getenv("OKTA_CLIENT_ID"),
            "client_secret": os.getenv("OKTA_CLIENT_SECRET"),
            "base_url": os.getenv("OKTA_BASE_URL")
        })
        
        # Decodificar JWT
        claims = jwt.get_unverified_claims(token)
        
        # Llamar a Okta para verificar
        user_id = claims["sub"]
        user = okta_client.get_user(user_id)
        
        # Extraer territorio del grupo
        grupos = user["groups"]
        territorio = extraer_territorio(grupos)  # "MX", "AR", etc.
        
        return {
            "usuario_id": user_id,
            "territorio": territorio,
            "grupos": grupos,
            "verificado": True
        }
    except JWTError:
        return {"error": "Invalid token"}
```

**Paso 4: Helpers**

```python
def extraer_territorio(grupos: list) -> str:
    """
    Grupos en Okta:
    - sales-mx
    - sales-ar
    - admin-global
    
    Extraer territorio del grupo.
    """
    for grupo in grupos:
        if "sales-mx" in grupo:
            return "MX"
        elif "sales-ar" in grupo:
            return "AR"
    return "UNKNOWN"
```

**Paso 5: Frontend envía token**

En `frontend/pages/api/chat.ts`:

```typescript
import { getSession } from "@auth0/nextjs-auth0";

export default async function handler(req, res) {
    const session = await getSession(req, res);
    
    if (!session) {
        return res.status(401).json({ error: "Not authenticated" });
    }
    
    // Enviar token al backend
    const response = await fetch("http://localhost:8000/chat", {
        method: "POST",
        headers: {
            "Authorization": `Bearer ${session.idToken}`,
            "Content-Type": "application/json"
        },
        body: JSON.stringify({
            query: req.body.query,
            auth_token: session.idToken
        })
    });
    
    return res.json(await response.json());
}
```
