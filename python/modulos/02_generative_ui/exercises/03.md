# Ejercicio 03 – Avanzado: Pipeline con registro de componentes y streaming

## Objetivo

Construir un pipeline completo de Generative UI que:
1. Procese un mensaje del usuario.
2. Genere una secuencia de "tool calls" simulados.
3. Mapee cada tool call al componente registrado correspondiente.
4. Emita los componentes renderizados de forma incremental (generador).

---

## Descripción

El patrón completo en TypeScript con Vercel AI SDK:

```typescript
const { stream } = createStreamableUI();
const result = await streamText({
  tools: { showChart: { execute: async (args) => { stream.update(<Chart {...args} />); } } }
});
```

---

## Requisitos

1. Implementar un **decorador de registro** `@componente("NombreComponente")`
   que almacene las clases en un diccionario `REGISTRO`.
2. Registrar al menos 2 componentes con su método `renderizar()`.
3. Función generadora `pipeline(mensaje) → Iterator[str]` que:
   - Simule 2-3 tool calls basados en el mensaje.
   - Para cada tool call, busque el componente en el registro.
   - `yield` el resultado de `renderizar()` con un pequeño retardo.
4. Mostrar en consola los componentes conforme llegan.

---

## Pistas

- Un decorador de registro es una función que recibe la clase y la almacena
  en un dict: `REGISTRO[nombre] = cls; return cls`.
- `yield` dentro de una función la convierte en generador.
- `time.sleep(0.05)` simula el streaming.

---

## Criterios de éxito

- [ ] Cada componente se imprime con un pequeño retardo (efecto streaming).
- [ ] Un tool call con componente desconocido imprime un aviso claro.
- [ ] El código es ejecutable con `python3 solutions/03.py`.
