# Ejercicio 01 – Básico: Handler serverless con ciclo de vida

## Objetivo

Implementar una función `handler(evento, contexto)` que simule el ciclo
de vida de una función AWS Lambda: inicialización costosa en cold start,
ejecución rápida en warm start, y respuesta estructurada.

---

## Descripción

En AWS Lambda, la inicialización de conexiones y modelos ocurre **fuera del
handler** para reutilizarse entre invocaciones:

```python
# FUERA del handler (cold start, una sola vez)
db_client = connect_to_db()

# DENTRO del handler (cada invocación)
def lambda_handler(event, context):
    result = db_client.query(event['id'])
    return {'statusCode': 200, 'body': result}
```

---

## Requisitos

1. Variable global `_CONEXION` inicializada a `None`.
2. Función `obtener_conexion()` que inicialice `_CONEXION` si es `None`
   (con un `time.sleep(0.1)` para simular el costo).
3. Función `handler(evento, contexto)` que:
   - Llame a `obtener_conexion()`.
   - Imprima si fue cold start o warm start.
   - Devuelva un dict con `statusCode`, `solicitud_id` y `cuerpo`.
4. Invocar el handler 3 veces y mostrar que el cold start solo ocurre la primera vez.

---

## Pistas

- Una variable global es `None` la primera vez que el módulo se carga.
- `time.perf_counter()` para medir duración de cada invocación.

---

## Criterios de éxito

- [ ] Solo la primera invocación muestra el mensaje de cold start.
- [ ] Las siguientes invocaciones son notablemente más rápidas.
- [ ] El código es ejecutable con `python3 solutions/01.py`.
