# Nodos: Las Funciones Ejecutables del Grafo

Los **nodos** son funciones Python que reciben el State, lo procesan, y lo devuelven actualizado.

Piénsalo así: Si el State es la data, los nodos son el procesamiento. ⚙️

---

## 🔄 ¿Qué es un Nodo?

```
Estado Inicial      Nodo Ejecuta      Estado Final
┌──────────┐       ┌─────────┐       ┌──────────┐
│ messages │──────▶│ Process │──────▶│ messages │
│ step     │       │ Logic   │       │ step     │
│ result   │       └─────────┘       │ result   │
└──────────┘                         └──────────┘
```

Un nodo es:
- ✅ Una función Python normal
- ✅ Recibe state: MyState
- ✅ Retorna diccionario con cambios
- ✅ Ejecutada por el grafo en orden

---

## 💻 Nivel 1: Nodo Básico

<BasicExample
  code={`from typing import TypedDict

class SimpleState(TypedDict):
    input_text: str
    output: str

def simple_node(state: SimpleState) -> dict:
    """Nodo más simple posible"""
    # 1. Lee del state
    text = state['input_text']
    
    # 2. Procesa
    result = text.upper()
    
    # 3. Retorna cambios
    return {"output": result}

# Uso:
state = {"input_text": "hola", "output": ""}
result = simple_node(state)
print(result)  # {"output": "HOLA"}
`}
  title="01_nodo_basico.py"
/>

**Cuándo usar**: Operaciones simples, transformaciones

## 💻 Nivel 2: Nodo con Manejo de Errores

<BasicExample
  code={`def robust_node(state: SimpleState) -> dict:
    """Nodo que maneja errores gracefully"""
    try:
        text = state.get('input_text', '')
        if not text:
            raise ValueError("input_text vacío")
        
        result = text.upper()
        return {
            "output": result,
            "error": None
        }
    except Exception as e:
        return {
            "output": "",
            "error": str(e)
        }

# El nodo nunca falla - siempre retorna algo
`}
  title="02_nodo_con_errores.py"
/>

**Ventaja**: Tu grafo no se rompe por excepciones  
**Cuándo usar**: Nodos que hacen I/O, llamadas a APIs

## 💻 Nivel 3: Nodo Asincronico

<AdvancedExample
  code={`import asyncio
from typing import TypedDict, Annotated
from operator import add

class AsyncState(TypedDict):
    queries: list[str]
    results: Annotated[list, add]
    processing_log: Annotated[list, add]

async def async_api_node(state: AsyncState) -> dict:
    """Nodo que hace I/O asincronico"""
    results = []
    logs = []
    
    # Ejecuta múltiples queries en paralelo
    for query in state['queries']:
        try:
            # Simula llamada a API
            await asyncio.sleep(0.1)  # En real: llamada HTTP
            result = f"Resultado de: {query}"
            results.append(result)
            logs.append(f"✓ Query: {query}")
        except Exception as e:
            logs.append(f"✗ Error en {query}: {e}")
    
    return {
        "results": results,
        "processing_log": logs
    }

# Usa el nodo en grafo:
# graph.add_node("api_call", async_api_node)  # Grafo lo ejecuta automáticamente
`}
  title="03_nodo_asincronico.py"
/>

**Ventaja**: Ejecuta múltiples operaciones en paralelo  
**Cuándo usar**: Llamadas a APIs, queries a DB, operaciones de red

## 🏗️ Patrones Comunes

### Patrón 1: Nodo de Validación

<BasicExample
  code={`class ValidationState(TypedDict):
    user_data: dict
    validation_errors: Annotated[list, add]
    is_valid: bool

def validation_node(state: ValidationState) -> dict:
    errors = []
    data = state['user_data']
    
    if not data.get('email'):
        errors.append("Email requerido")
    if not data.get('age') or data['age'] < 18:
        errors.append("Debe ser mayor de 18")
    
    return {
        "validation_errors": errors,
        "is_valid": len(errors) == 0
    }
`}
  title="patron_1_validacion.py"
/>

### Patrón 2: Nodo de Transformación

<BasicExample
  code={`def transform_node(state: SimpleState) -> dict:
    """Convierte datos de un formato a otro"""
    raw_data = state.get('raw_input', '')
    
    # CSV → JSON
    lines = raw_data.split('\\n')
    headers = lines[0].split(',')
    rows = [dict(zip(headers, line.split(','))) 
            for line in lines[1:]]
    
    return {
        "structured_data": rows,
        "row_count": len(rows)
    }
`}
  title="patron_2_transformacion.py"
/>

### Patrón 3: Nodo que Registra Logs

<BasicExample
  code={`import json
from datetime import datetime

def logging_node(state: SimpleState) -> dict:
    """Nodo que registra todo lo que sucede"""
    timestamp = datetime.now().isoformat()
    
    log_entry = {
        "timestamp": timestamp,
        "step": state.get('current_step', 'unknown'),
        "input_size": len(str(state.get('input_text', ''))),
        "status": "ok"
    }
    
    return {
        "logs": [json.dumps(log_entry)],
        "last_log_time": timestamp
    }
`}
  title="patron_3_logging.py"
