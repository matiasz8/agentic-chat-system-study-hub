## Entiende

Aristas conectan nodos con lógica condicional:

```
Nodo 1 (Verificar) 
  → ¿Autorizado?
    ✅ SÍ → Nodo 2 (Buscar)
    ❌ NO → Error

Nodo 2 (Buscar)
  → Encontró resultados?
    ✅ SÍ → Nodo 3 (Validar)
    ❌ NO → Error
```
