## 💡 Por Qué LangGraph

Antes: `if/else` anidados. Ahora: grafos que piensan por sí solos.

```python
# Antes (complicado)
if usuario_pregunta_stock:
    stock = query_database()
    if stock < 10:
        alerta = generar_alerta()
        # ... más lógica

# Ahora (LangGraph)
grafo = StateGraph(AgentState)
grafo.add_node("agent", agent_node)
grafo.add_node("query_db", query_db_node)
grafo.add_conditional_edges("agent", router)
# Listo. El grafo lo maneja.
```
