# Ejercicio 03 – Avanzado: Máquina de estados con aristas condicionales

## Objetivo

Implementar una `MaquinaEstados` que ejecute un grafo de agente paso a paso,
usando un estado compartido y aristas condicionales que decidan la ruta en
tiempo de ejecución.

---

## Descripción

LangGraph es fundamentalmente una máquina de estados donde:
- **Nodos** son funciones que reciben y devuelven el estado.
- **Aristas condicionales** son funciones que leen el estado y retornan
  el nombre del próximo nodo.

```python
# En LangGraph real:
grafo.add_conditional_edges("clasificar", routing_fn, {
    "consulta": "consultar_bd",
    "accion": "ejecutar_accion",
})
```

---

## Requisitos

1. Clase `Estado` (dataclass) con al menos 3 campos relevantes al dominio.
2. Clase `MaquinaEstados` con:
   - `agregar_nodo(nombre, funcion)`.
   - `agregar_arista(origen, destino)`.
   - `agregar_arista_condicional(origen, router_fn)`.
   - `ejecutar(estado) -> Estado`: itera hasta llegar al nodo final.
3. Construir un grafo de al menos 4 nodos con una arista condicional.
4. Ejecutar el grafo con 2 estados iniciales distintos que sigan rutas diferentes.

---

## Pistas

- La función `router_fn(estado) -> str` devuelve el nombre del siguiente nodo.
- El bucle de ejecución termina cuando se alcanza el nodo final definido.
- Imprime la transición en cada paso para visualizar el recorrido.

---

## Criterios de éxito

- [ ] Dos estados distintos siguen rutas diferentes a través del grafo.
- [ ] La ejecución termina siempre (no hay loop infinito).
- [ ] El código es ejecutable con `python3 solutions/03.py`.
