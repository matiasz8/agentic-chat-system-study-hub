# Ejercicio 3: Retriever multimodal

## 🎯 Objetivo
Construir un retriever que indexe texto e “imágenes” descritas por metadata, permitiendo recuperación cruzada entre modalidades.

## 📋 Descripción
Implementa una clase `MultimodalRetriever` con métodos para agregar documentos de texto y descripciones de imagen. Todas las entradas deben convertirse a un mismo espacio vectorial simplificado. Luego implementa búsquedas como:

- Texto → imágenes relacionadas.
- Texto → textos relacionados.
- Imagen descriptiva → textos relacionados.

Puedes simular imágenes con descripciones como `"gato en sofá con manta"`.

## 💡 Pistas
- Usa el mismo vocabulario para ambas modalidades.
- Un embedder basado en tokens compartidos ya alcanza para mostrar la idea.
- Filtrar por modalidad objetivo ayuda a explicar cross-modal retrieval.

## ✅ Criterios de Éxito
- El índice acepta al menos dos modalidades.
- Las búsquedas recuperan elementos razonables según la consulta.
- La salida muestra `item_id`, modalidad y score.

## 🚀 Bonus
Agrega una penalización suave por longitud para evitar que descripciones largas dominen el ranking.
