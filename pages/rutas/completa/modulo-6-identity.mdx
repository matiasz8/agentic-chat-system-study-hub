## Entiende

La pregunta de oro:
**¿Cómo aseguramos que vendedor MX NO ve datos de AR?**

Respuesta: Identity Forwarding.

```
1. Usuario loguea con Okta (MX grupo)
2. Token llega a frontend
3. Frontend envía token a backend
4. Backend valida con Okta
5. Backend filtra por territorio (MX)
6. Búsqueda MCP usa territorio (MX)
```

Sin esto = compliance breach. Vendedor MX ve TODO.
