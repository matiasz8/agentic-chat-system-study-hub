# Ejercicio 02 – Intermedio: Tokens de alcance reducido

## Objetivo

Implementar un sistema que genere tokens efímeros con permisos mínimos
para operaciones específicas, siguiendo el principio de mínimo privilegio.

---

## Descripción

En lugar de pasar el token maestro del usuario a cada servicio, el agente
genera tokens de corto alcance:

```
Token maestro: leer:*, escribir:requisicion, cancelar:orden
                         │
                         ▼ generar_token_alcance("leer:stock", "inventario/MED-001")
Token scoped: solo leer:stock en inventario/MED-001, expira en 5 minutos
```

Esto reduce el radio de explosión si un servicio downstream es comprometido.

---

## Requisitos

1. Dataclass `TokenAlcance` con: `usuario_id`, `operacion`, `recurso`, `expira_en`, `id`.
2. Diccionario `POLITICAS` que mapee roles a listas de operaciones permitidas.
3. Función `generar_token(contexto, operacion, recurso, duracion_seg)` que:
   - Verifique si el rol del usuario permite la operación.
   - Cree y devuelva un `TokenAlcance`.
   - Lance `PermissionError` si no está permitido.
4. Función `validar_token(token, operacion_requerida) -> bool` que verifique
   que el token es válido (vigente y con la operación correcta).
5. Demostrar acceso permitido, acceso denegado y token expirado.

---

## Pistas

- `time.time() + duracion_seg` para calcular la expiración.
- `time.time() > token.expira_en` para verificar expiración.

---

## Criterios de éxito

- [ ] Token generado para operación permitida es válido.
- [ ] `PermissionError` al solicitar operación no autorizada para el rol.
- [ ] Token expirado no pasa la validación.
- [ ] El código es ejecutable con `python3 solutions/02.py`.
