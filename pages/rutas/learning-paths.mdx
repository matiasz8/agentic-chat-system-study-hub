# 🎯 Learning Paths: Elige tu Camino

> 📚 LEARNING PATHS
Dos caminos: corto o completo.

> Dos rutas explícitas para llegar a Ask Sage: **Rápida** (1 semana) o **Completa** (2-3 semanas)

---

## 🏃 RUTA RÁPIDA (7 días - MVP funcional)

> Para: Necesito Ask Sage funcionando YA

**Meta**: Ask Sage MVP en producción en 1 semana

```
DÍA 1-2: FRONTEND (Streaming + UX)
├─ 00-vercel-intro (30 min)
├─ 01-streaming (1 h) ⭐ CRÍTICO
├─ 02-generative-ui (1 h)
└─ Código: AskSageChat.tsx

DÍA 3-4: ORCHESTRATION (LangGraph)
├─ 10-fundamentos-grafos (30 min)
├─ 11-state (1 h) ⭐ CRÍTICO
├─ 12-nodos (1 h)
└─ Código: ask_sage_graph.py (3 nodos básicos)

DÍA 5: RUNTIME/IDENTITY (Seguridad)
├─ 21-identity-forwarding (2 h) ⭐⭐⭐ CRÍTICO
└─ Código: nodo_verificar_identidad (mock Okta)

DÍA 6: DATA LAYER (Búsqueda)
├─ 30-mcp-protocol (1 h)
└─ Código: nodo_buscar_en_mcp (búsqueda simulada)

DÍA 7: TESTING + DEPLOY
├─ ask-sage-validation (1 h)
├─ Ejecutar tests
└─ Deploy a AWS (básico)
```

**Resultado**: Chat funcional con seguridad básica ✅

## 🎯 ¿Cuál Elegir?

### Elige RUTA RÁPIDA si:
- ✅ Necesitas Ask Sage en 1 semana
- ✅ Solo quieres lo CRÍTICO
- ✅ Presupuesto/tiempo limitado
- ✅ Ya tienes experiencia con LangGraph

### Elige RUTA COMPLETA si:
- ✅ Quieres dominar la arquitectura
- ✅ Tienes 3 semanas disponibles
- ✅ Necesitas ir a producción confiable
- ✅ Quieres hacer entrevistas técnicas

### Recomendación Oficial (Tu Jefe):
**RUTA RÁPIDA + Semana 4 de mejoras** = Mejor relación costo/tiempo

## 🔗 Módulo ↔ Código: Paralelismo

Cada módulo de la web tiene código correspondiente en **ask-sage-starter**.

### Ejemplo: State (Módulo 11)

```
PÁGINA WEB:
/orchestration/11-state.mdx
├─ Concepto: AskSageState TypedDict
├─ Ejemplo: State centralizado
└─ Ejercicio: Define tu State

↓ CORRESPONDE A ↓

CÓDIGO (ask-sage-starter):
backend/ask_sage_graph.py
├─ Línea 5-20: class AskSageState(TypedDict)
├─ Línea 25-35: Uso en nodos
└─ Línea 60-65: Actualización

INSTRUCCIONES:
1. Lee /orchestration/11-state (45 min)
2. Abre backend/ask_sage_graph.py
3. Reconoce AskSageState
4. Modifica un campo (ej: agrega "temperatura")
5. VES CAMBIOS EN http://localhost:3000
```
