# CI/CD Automatizado

> CI/CD Validation
Automatización antes de producción.

Correr tests automáticamente en cada commit/PR.

---

## 🎯 Objetivo

- ✅ Tests corren automáticamente en GitHub
- ✅ PR no puede mergearse si tests fallan
- ✅ Reporte de cobertura
- ✅ Sin intervención manual

---

## 🔄 Workflow Básico

```
Developer hace commit
        ↓
GitHub detecta push
        ↓
GitHub Actions corre pytest
        ↓
Tests pasan? → ✅ Permite merge
Tests fallan? → ❌ Bloquea merge
```

---

## 📄 .github/workflows/test.yml

Este archivo (en `.github/workflows/`) define el workflow:

```yaml
name: Tests

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.9'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r python/requirements.txt

      - name: Run tests
        run: pytest python/ -v --cov=python

      - name: Upload coverage
        uses: codecov/codecov-action@v3
```

---

## ✅ Qué Hace

1. **Trigger:** En cada push a `main` o `develop`
2. **Setup:** Instala Python + dependencias
3. **Test:** Corre `pytest python/ -v`
4. **Coverage:** Genera reporte de cobertura
5. **Status:** ✅ o ❌ en la PR

---

## 🛡️ Branch Protection Rules

En GitHub (Settings → Branches):

```
Branch: main
- Require status checks to pass before merging
- Require code review before merging (1 approval)
- Dismiss stale review approvals
- Require branches to be up to date
```

**Resultado:** No puedes mergear sin que los tests pasen.

---

## 📊 Matriz de Tests

Para testear múltiples versiones de Python:

```yaml
jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ['3.9', '3.10', '3.11']

    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: ${{ matrix.python-version }}
```

## 🚀 Setup en Tu Repo

### Paso 1: Crear `.github/workflows/test.yml`
```bash
mkdir -p .github/workflows
# Copiar contenido workflow (ver abajo)
```

### Paso 2: Hacer commit
```bash
git add .github/workflows/test.yml
git commit -m "Add CI/CD: GitHub Actions workflow"
git push
```

### Paso 3: Esperar que corra
GitHub Actions corre automáticamente. Ver en:
- GitHub → Actions tab
- PR → Checks section

## ✨ Características Avanzadas

### 1. Notify Slack en Failure
```yaml
- name: Notify Slack
  if: failure()
  uses: slackapi/slack-github-action@v1
  with:
    webhook-url: ${{ secrets.SLACK_WEBHOOK }}
```

### 2. Schedule Nightly Builds
```yaml
on:
  schedule:
    - cron: '0 2 * * *'  # 2 AM daily
```

### 3. Reporte de Performance
```yaml
- name: Store benchmark
  uses: benchmark-action/github-action-benchmark@v1
```
