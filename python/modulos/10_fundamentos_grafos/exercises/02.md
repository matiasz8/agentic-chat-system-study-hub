# Ejercicio 02 – Intermedio: BFS/DFS y detección de ciclos

## Objetivo

Extender el grafo con dos algoritmos de recorrido (BFS y DFS) y una función
que detecte si el grafo contiene ciclos.

---

## Descripción

Los ciclos en un grafo de agente representan bucles de reintento. Conocer si
existen y dónde están es fundamental para evitar loops infinitos.

---

## Requisitos

1. Implementar `bfs(inicio) -> list[str]`: recorrido en amplitud usando `deque`.
2. Implementar `dfs(inicio) -> list[str]`: recorrido en profundidad (recursivo
   o iterativo).
3. Implementar `tiene_ciclo() -> bool` usando coloreo de nodos (blanco/gris/negro).
4. Crear dos grafos:
   - Uno acíclico (flujo lineal del agente).
   - Uno con un ciclo (el agente puede reintentar).
5. Mostrar el resultado de BFS, DFS y detección de ciclo para ambos.

---

## Pistas

- BFS usa `collections.deque` como cola (FIFO).
- DFS recursivo necesita un set de `visitados` para no repetir nodos.
- Para detectar ciclos: un nodo "gris" (en pila) apunta a sí mismo → ciclo.

---

## Criterios de éxito

- [ ] BFS y DFS devuelven órdenes distintos para el mismo grafo.
- [ ] `tiene_ciclo()` devuelve `False` para el grafo lineal y `True` para el ciclico.
- [ ] El código es ejecutable con `python3 solutions/02.py`.
