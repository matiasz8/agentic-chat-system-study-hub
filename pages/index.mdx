# 🤖 Agentic Chat System: Full Stack Study Hub

> **Arquitectura de 3 Capas Integradas para Construir Chat IA Empresarial**

Este es un **hub de estudio universitario** completo sobre cómo construir un **sistema de chat IA con Generative UI** siguiendo la arquitectura moderna recomendada: 
- **Frontend** (Vercel AI SDK)
- **Orchestration** (LangGraph) 
- **Runtime** (AWS AgentCore)
- **Validation** (Testing & CI/CD)

---

## 🎯 ¿Por Qué Este Hub Existe?

Hace 5 años, construir un agente de IA significaba escribir `if/else` anidados. **LangGraph cambió todo**: te permite escribir grafos donde la IA "piensa en círculos" hasta encontrar la respuesta correcta.

Este hub te prepara para construir sistemas como **Ask Sage** (del caso de uso farmacéutico), donde el agente puede:
- 🗄️ Consultar bases de datos
- 🤖 Tomar decisiones automáticas
- ⏸️ Pausarse para aprobación humana
- 💾 Recordar contexto entre preguntas
- ✅ Todo sin reescribir lógica cada vez

---

## 📚 Las 4 Capas

### 🧠 **CAPA 1: Orchestration (LangGraph)**
El cerebro del agente. Grafos ejecutables que piensan.
- State centralizado
- Nodos y Aristas condicionales
- Checkpoints para persistencia

### 🎨 **CAPA 2: Frontend (Vercel AI SDK)**
La cara del agente. Streaming + Generative UI.
- Streaming de tokens en tiempo real
- Componentes React desde el servidor
- UX moderna y responsiva

### ☁️ **CAPA 3: Runtime (AWS Bedrock AgentCore)**
La infraestructura del agente. Serverless + Seguridad.
- Deployment sin servidor
- Identity forwarding (credenciales delegadas)
- Cedar policies (control de acceso)

### ✅ **CAPA 4: Validation (Testing)**
**NEW** - La calidad del agente. Prompts testeados.
- Testing de prompts
- Validación de workflows
- CI/CD automatizado
