# Ejercicio 3: Simulador de Pipeline de Despliegue

## 🎯 Objetivo
Construir un simulador de pipeline que modele source, build, test, push, deploy, smoke test y rollback.

## 📋 Descripción
Implementa una clase orquestadora que ejecute etapas en orden. Si el smoke test falla, el despliegue debe revertir automáticamente al entorno anterior. Usa estados legibles para mostrar la historia del release.

## 💡 Pistas
- Representa cada etapa con una función o dataclass.
- Guarda la versión o color actualmente activo.
- Diferencia entre despliegue exitoso y rollback.
- Imprime cada transición para hacer el flujo visible.

## ✅ Criterios de Éxito
- Todas las etapas del pipeline quedan modeladas.
- El rollback se ejecuta cuando falla el smoke test.
- La salida deja claro cuál versión quedó activa.
- El programa corre sin librerías externas.

## 🚀 Bonus
Añade métricas simples de duración por etapa y una política de aprobación manual antes de producción.
