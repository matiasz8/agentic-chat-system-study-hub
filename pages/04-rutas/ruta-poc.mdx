# Ruta POC: Aprender Haciendo

**Duración:** 16 horas | **Requisitos:** Node.js, básico de React | **Formato:** Tutorial paso-a-paso

Para desarrolladores que quieren construir un agente funcional de principio a fin.

## 🛠️ Proyecto

Construirás una **versión simplificada de Ask Sage** que:
- ✓ Toma consultas en natural language
- ✓ Usa LangGraph para orquestar
- ✓ Streamea respuestas en tiempo real
- ✓ Pasa validaciones automáticas

## 📋 Pasos

1. **Setup ambiente** (1h)
   - Node.js, npm, editor
   - Clonar y entender estructura

2. **Aprender LangGraph** (2h)
   - Conceptos de grafos
   - State management
   - Nodos y aristas

3. **Implementar tu primer grafo** (2h)
   - Crear nodos simples
   - Conectarlos en un grafo
   - Pruebas locales

4. **Frontend con streaming** (2h)
   - Vercel AI SDK
   - Componentes React
   - Streaming de respuestas

5. **Testing local** (2h)
   - Unit tests para nodos
   - Integration tests
   - E2E tests

6. **Deploy local** (2h)
   - Docker o similar
   - Verificar en navegador
   - Simular requests

7. **Validación final** (2h)
   - Checklist completitud
   - Performance básico
   - Documentación

## ✅ Al finalizar

Tendrás:
- ✓ Un agente funcionando en tu máquina
- ✓ Código que entiendes completamente
- ✓ Base para productivizar
