# Ejercicio 01 – Básico: Selector de componente UI

## Objetivo

Implementar una función `elegir_componente(datos)` que reciba un diccionario
con un campo `"tipo"` y devuelva el nombre del componente React más adecuado.

---

## Descripción

En Generative UI, el backend decide qué componente renderizar según los datos:

```typescript
// Backend TypeScript
if (data.type === "chart") return <BarChart {...data} />;
if (data.type === "alert") return <Alert {...data} />;
return <TextBlock text={data.text} />;
```

---

## Requisitos

1. Definir al menos 3 clases de componentes: `Texto`, `Grafico`, `Alerta`.
2. Cada clase debe tener un método `renderizar()` que devuelva un string.
3. La función `elegir_componente(datos)` debe:
   - Retornar `Grafico` si `datos["tipo"] == "grafico"`.
   - Retornar `Alerta` si `datos["tipo"] == "alerta"`.
   - Retornar `Texto` en cualquier otro caso.
4. Probar con al menos 3 diccionarios distintos e imprimir el resultado.

---

## Pistas

- Usa `datos.get("tipo", "texto")` para evitar `KeyError`.
- El método `renderizar()` puede simplemente devolver una cadena con el nombre
  del componente y los datos relevantes.

---

## Criterios de éxito

- [ ] Cada tipo de datos activa el componente correcto.
- [ ] El método `renderizar()` devuelve texto legible para cada componente.
- [ ] El código es ejecutable con `python3 solutions/01.py`.
