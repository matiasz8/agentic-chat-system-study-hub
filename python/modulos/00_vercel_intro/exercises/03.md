# Ejercicio 03 – Avanzado: Registro de proveedores y streaming

## Objetivo

Implementar un **registro de proveedores** que permita seleccionar el proveedor
en tiempo de ejecución y un **generador de streaming** que emita tokens de forma
incremental.

---

## Descripción

En el Vercel AI SDK existe `createProviderRegistry()` para registrar proveedores
y `streamText()` que devuelve un async iterable de tokens.

```typescript
const registry = createProviderRegistry({ openai, anthropic });
const { textStream } = await streamText({
  model: registry.languageModel("openai:gpt-4o"),
  prompt: "...",
});
for await (const chunk of textStream) { process.stdout.write(chunk); }
```

---

## Requisitos

1. Clase `RegistroProveedores`:
   - `registrar(id, modelos)`: registra un proveedor con sus modelos.
   - `resolver(id, modelo)`: valida y devuelve el modelo, o lanza `KeyError`/`ValueError`.
2. Generador `stream_tokens(modelo, texto)`:
   - `yield` token a token (separar por espacios).
   - Simular un retardo de 10–30 ms por token con `time.sleep`.
3. Función principal que:
   - Registre al menos 2 proveedores.
   - Elija uno, valide el modelo con `resolver()`.
   - Imprima tokens en tiempo real (sin salto de línea hasta el final).
4. Manejar el caso de modelo inválido imprimiendo un mensaje de error claro.

---

## Pistas

- Un **generador** en Python usa `yield` en lugar de `return`.
- `print(token, end="", flush=True)` imprime sin salto de línea.
- `random.uniform(0.01, 0.03)` da un retardo variable.

---

## Criterios de éxito

- [ ] El registro lanza `KeyError` para proveedores inexistentes.
- [ ] El streaming imprime tokens progresivamente en la misma línea.
- [ ] El código es ejecutable con `python3 solutions/03.py`.
