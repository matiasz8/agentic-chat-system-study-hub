## 🎯 Requisitos del Proyecto

Se solicitó:
> "Chatbot para vendedores farmacéuticos que conozca:
> - Dosis por condición
> - Contraindicaciones
> - Pero cada vendedor solo ve sus territorios"

Esto requiere:
- ✅ **Capa 1: Frontend** - Streaming + Generative UI (Vendedor ve tablas interactivas)
- ✅ **Capa 2: Orchestration** - LangGraph (Decisiones: buscar, generar, validar)
- ✅ **Capa 3: Runtime** - Identity Forwarding (Vendedor MX ≠ Vendedor AR)
- ✅ **Capa 4: Data** - MCP + Embeddings (PDFs, videos, bases de datos)
- ✅ **Capa 5: Validation** - Tests (Seguridad, compliance, SLA)

**Este hub te enseña EXACTAMENTE eso.**

## 🎓 Pro Tips

1. **Lee primero, codifica después**  
   Cada módulo explica el "POR QUÉ". Luego el código muestra el "CÓMO".

2. **Usa Module Map**  
   Cuando leas un módulo, mira `[Módulo Map](/rutas/module-map)` para ver dónde está en ask-sage-starter.

3. **Modifica el código mientras lees**  
   La mejor forma de aprender es cambiar cosas y ver qué pasa.

4. **Prioriza lo CRÍTICO**  
   Si tienes 1 semana, salta a [Ruta Rápida](/rutas/learning-paths) - solo 7 módulos.
