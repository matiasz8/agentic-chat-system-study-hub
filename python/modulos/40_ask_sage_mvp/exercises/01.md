# Ejercicio 1: Pipeline de Ingestión de Documentos

## 🎯 Objetivo
Construir una función de ingestión que lea texto, lo divida en chunks de N palabras y guarde metadatos útiles para búsqueda posterior.

## 📋 Descripción
Implementa una estructura `Chunk` y una función `ingest_document(doc_id, text, chunk_size)` que devuelva una lista de chunks con `doc_id`, `chunk_id`, `text`, `start_word` y `end_word`.

## 💡 Pistas
- Usa `text.split()` para obtener palabras.
- Recorre la lista con saltos de `chunk_size`.
- Genera `chunk_id` con un contador incremental.
- Conserva también el último chunk aunque sea corto.

## ✅ Criterios de Éxito
- El documento queda dividido en chunks consistentes.
- Cada chunk mantiene trazabilidad al origen.
- El programa imprime los chunks generados.
- El archivo tiene `main()` y puede ejecutarse directo.

## 🚀 Bonus
Agrega un campo opcional `source` para indicar si el texto vino de wiki, PDF o base de conocimiento.
