# Ejercicio 2: Formateador SSE Compatible

        ## 🎯 Objetivo
        Implementar un formateador que convierta un stream de tokens en eventos SSE válidos con `id`, `event`, `retry` y `data`.

        ## 📋 Descripción
        Define una función `format_sse(event_id: int, data: str, event: str = "token", retry: int = 1500) -> str`. Debe retornar una cadena con el framing SSE correcto y terminar con una línea vacía. Luego consume una lista de tokens y conviértela en una secuencia de eventos imprimibles.

        Asegúrate de enviar un evento final como `done` con `data: [DONE]`.

        ## 💡 Pistas
        - El formato SSE usa `clave: valor` por línea.
        - El bloque termina con `

`.
        - Si `data` tiene múltiples líneas, cada una debe empezar con `data:`.
        - Puedes usar `enumerate(..., start=1)` para generar IDs.

        ## ✅ Criterios de Éxito
        - Cada evento incluye `id`, `event`, `retry` y `data`.
        - La salida es válida para un cliente estilo `EventSource`.
        - Hay un evento final de cierre.
        - El script es ejecutable y produce salida educativa.

        ## 🚀 Bonus
        Agrega soporte para comentarios SSE (`: ping`) o para eventos personalizados como `metadata`.
